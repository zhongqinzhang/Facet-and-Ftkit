November 8, 2026 — Facet 0.1.0-beta.1 (Beta 1, local candidate)
=============================================================

First beta testing version. The full version is 0.1.0-beta.1 throughout About,
application metadata, installer naming, and this documentation. Windows MSI
uses the numeric product version 0.1.0; the full beta identifier is retained in
the application and release manifest.

Scientific data corrections:
- One shared Cordero table supplies frontend radii and Rust bonding constants:
  96 reference entries, including 12 additions; 10 numerical values change.
- Covalent auto-bond caches include the data revision. Older caches are rebuilt;
  manual bonds, deletion overrides, coordinates, colors, and saved size
  multipliers are preserved. Related spheres and automatic bonds may change.
- Lr is corrected to [Rn] 5f14 7s2 7p1. NIST supplies H–Hs references; Smits et al.
  (2023), Table 2, supplies Mt–Og theoretical configurations.
- The status bar identifies predictions, estimates, compiled radii, and fallback
  radii, with source details. Existing van der Waals numeric values are retained.
- Legacy palette descriptions no longer claim an unverified exact copy of
  official VESTA or Materials Studio defaults. Palette colors and IDs are unchanged.
- Third-party notices now include the identified NIST, CC BY 4.0, and BODR sources.
- New projects and exported structure packages use the build application version
  instead of the old 0.0.0 placeholder; existing project metadata is retained.

Use this as a local testing candidate. It has not been installed or publicly
published in this task. No automated tests were run. Consult the accompanying
release README for the checks actually completed; this note does not certify
native installation, first launch, upgrade, or uninstallation.

Historical sections below describe their original candidates. Beta 1 supersedes
those data/provenance findings: newVESTA authorship is confirmed and the current
reference corrections are described above. Older version numbers are historical.

2. STM and rendering
====================
Complete CHGCAR, CHG, and PARCHG grids can be used for STM calculations.
Values reconstructed for visualization remain ineligible. For a physical
bias-window interpretation, prepare the appropriate partial charge density;
a total charge density by itself does not define that energy window.

Density smoothing acts on the 3D input before calculation and changes the
result. Image smoothing acts on the calculated display without changing raw
data exports. Both are off by default for a new STM. Base structure and
overlay atoms have separate whole-layer visibility controls.
New overlays show bonds and use a 0–1 by 0–1 coverage range.

The update includes independent cell-frame visibility, corrected occlusion
and dashed-line gaps, worker-based display-mesh preparation, and reuse of
completed display results. GIF export settings can be moved by dragging
the panel.

3. Coordination polyhedra and editing
=====================================
Use Coordination polyhedra in the atoms-and-bonds section to create groups.
Each group defines central atoms, ligands, and a coordination rule based on
existing bonds or distance. Face color, edges, opacity, and highlights are
editable. Source atom positions remain unchanged.
Save/discard prompts and display-range input handling have been refined.

4. Projects, recovery, and file safety
======================================
External densities retain the source information recorded when loaded.
Changed or unavailable files produce a clear notice; keep the original
files to reopen the project. Relinking checks their recorded identity.
Some newer files can be opened in a read-only compatibility preview.
The notice identifies omitted features and disabled operations.

The October 23 build used Project 33, structure package 25, sequence
package 12, and phonon package 8. These are historical format versions;
see section 0 for the current source. That language update did not change them.
Form input history is disabled and cleared by the desktop application.

5. ftkit companion package
==========================
The accompanying Linux x86_64 archive is
ftkit-0.1.3-preview-20261022-phononfix-linux-x86_64.tar.gz.

and checks for cell or mass conflicts later in the file.
This release reuses that archive unchanged. Linux runtime and old-kernel
compatibility remain subject to the limitations in its BUILDINFO.json.
