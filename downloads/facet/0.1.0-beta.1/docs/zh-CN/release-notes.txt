2026-11-08 — Facet 0.1.0-beta.1（Beta 1，本地候选）
================================================

首个 Beta 测试版本。About、应用标识、安装包命名和本文档使用完整版本
0.1.0-beta.1。Windows MSI 的数字产品版本为 0.1.0；应用和发行清单保留
完整 Beta 标识。

科学数据修正：
- 前端半径和 Rust 判键常量共同读取一份 Cordero 表：96 项文献参考值，
  补入 12 项，其中 10 项数值改变。
- 自动共价键缓存纳入半径表版本；旧缓存会重新计算。手工键、手工删除
  自动键的记录、坐标、颜色及保存的尺寸比例保留，相关球大小和自动键可能改变。
- Lr 修正为 [Rn] 5f14 7s2 7p1。H–Hs 采用 NIST，Mt–Og 采用 Smits 等
  （2023）表 2 的理论组态。
- 状态栏区分理论预测、估算、汇编和兜底，并提供来源说明；范德华数值保持不变。
- 纠正旧配色来源说明，不再冒称 VESTA 或 Materials Studio 官方默认表的
  精确副本；配色数值和已有 ID 保持不变。
- 许可清单补入 NIST、CC BY 4.0 与 BODR 的适用声明和来源。
- 新建项目及导出结构包的版本标记读取实际构建版本，修正原有 0.0.0 占位值；
  旧项目保存的原始版本信息保留。

此版本为本地测试候选，本轮未安装或公开发布，也未运行自动化测试。
实际完成的检查见随包 README；本条更新说明不代表已验收原生安装、
首次启动、升级或卸载。

以下是各候选当时的历史记录。Beta 1 已确认 newVESTA 自有归属并完成上述
数据修正；旧来源待办以当前来源说明为准，以下旧版本号不代表本包版本。

在原子与键区域展开“配位多面体”，使用分组管理中心、配体和配位规则。
可按已有键或距离生成，面色、棱线、透明度和高光可分别调整。
统一保存与放弃修改提示；无效显示范围输入保留上一次有效范围。

项目与文件
外部密度保留载入时记录的来源信息和校验值；文件变化或丢失时明确提示。
部分较新文件可只读兼容预览，并提示未显示内容及受限制操作。

2. Facet 0.1.1 Alpha · ABACUS、矢量与适配视图修复
====================================================
2026-09-30

ABACUS STRU 导入
----------------
支持 v / vel / velocity 速度属性，导入时从 ABACUS 原子单位换算为 Å/fs，
与已有磁矩分开显示。支持 magmom 别名、属性混排、D/d 科学计数法，
内容识别和解析采用一致的 #、// 注释规则。
已使用 96 原子的 STRU_300K 回归样例验证几何、约束、初始磁矩和速度。

sc / constrain、lambda 及其他附加参数片段保留为原始导入记录；
导入成功后明确提示哪些参数未应用为 Facet 可编辑约束或显示矢量。
记录随项目保存、重开和恢复数据保留。缺少完整晶格、非法数值、
错误分量数量和重复的已知属性仍会阻止导入。

导入错误提示
------------
修复普通 2D/3D 工作区错误提示被画布遮住的问题。
提示可换行、滚动和关闭；欢迎页继续显示内嵌错误。
单个结构导入失败时保留当前项目，修正源文件后可重新打开。

箭头长度与 Fit
--------------
新导入矢量按每组最大非零模长建立初始长度基准，组内仍保持真实比例。
磁矩、速度等分别定标；显示缩放不会改写科学数值。
已保存的外观继续优先使用，不会在重开时自动重新缩短。

修复 3D 带磁矩场景中，普通重绘取消待执行的空格/工具栏 Fit 请求。
视图切换和结构替换仍会使过期的取景操作失效，避免影响新结构。

手册与安装
----------
中文手册新增“安装与五分钟上手”及 ABACUS 专节，补充默认箭头长度、
Fit、导入提示和常见问题；核对成键元素、原子补全与 STM 显示说明。
本包沿用 0.1.1 Alpha 与 MSI 数字版本 0.1.1，保留既有升级标识。
安装前保存工作并退出 Facet；包名中的日期用于区分同版本构建。
手册可在安装目录通过“使用手册”快捷方式打开，也随安装包单独提供。

兼容边界
--------
只读取 STRU 自身；依赖外部 INPUT 的 latname 才能确定晶胞时仍需补齐
LATTICE_VECTORS。本版不提供 STRU 回写。原始导入记录不是当前计算设置，
导出到其他结构格式不保证携带这些额外信息，建议保留原文件并保存项目。

4. Facet 0.1.1 Alpha
====================
2026-09-25

声子与模式查看
--------------
支持 QE 声子和 ftkit 301/302 生成的声子 .facet，保留模式、质量、
复位移和各 q 点。频率可切换 cm⁻¹、THz、meV；单 q 点声子谱改为
一条频率线和模式点，多 q 点保留色散图。支持模式振动、位移箭头与 GIF。
修复声子 Project 在 2D 保存后重开时的画面恢复问题。

矢量操作与默认尺寸
------------------
列表颜色圆点可直接改色；已有矢量选择时只改所选矢量，
未选中时修改点击行代表的单根或整组。支持撤销和 Esc 取消本次调色。
显示长度和粗度可分别调节，保存后重开保留。

新声子箭头长度设为此前公共尺寸基准的 50%，新 ftkit 磁矩为 85%；
粗度和各自颜色、位置保持。磁矩默认由 ftkit 写入，声子默认由 Facet 初始化。
202 批量项目共用磁矩显示比例。已保存外观优先，不会在重开时重复缩短。
位移箭头在平衡位置为零，最大位移处最长；不把它作为速度箭头。

磁结构、文件与 STM
------------------
与 ftkit 0.1.3 配套：201 是静态磁结构，202 是批量磁结构项目，
101/103 仍为序列，301/302 为声子；不再用帧数区分静态与轨迹。
旧 ftkit 输出的单帧磁序列需要重新转换，保留旧格式读取。
打开不兼容或损坏项目失败时保留当前项目，并报告错误。
本版还包含 PARCHG 恒高/恒流 STM、科学色谱设置和数据导出。

安装与文档
----------
MSI 内部版本为 0.1.1，保留既有升级标识。
先保存工作并关闭正在运行的 Facet，再安装；本包不自动发布到服务器。
Windows 需要 WebView2 145 或更新版本；缺少时安装程序联网补装。
中文使用手册已补充声子、矢量、磁文件分类和 STM 章节。
本版可读取配套 ftkit 输出；旧版报 schema version 20 时请升级。

主程序为 Facet.exe。
选择 D:\ 等盘符根目录时，安装位置自动补为 D:\Facet。
安装目录中的“使用手册”快捷方式，用系统默认文本编辑器打开。
官方主题的可导入副本位于 presets\themes。
缺少 WebView2 时，安装程序联网补装。

此版取消了“Uninstall Facet”快捷方式，避免创建该快捷方式时报错。
旧版同名快捷方式在升级时清理；卸载请用 Windows“已安装的应用”。

升级时先清理安装器创建的旧“使用手册”快捷方式，再重新创建。

本次更新：文件拖入与来源路径
--------------------------
新增 Windows 虚拟文件拖入接收，用于 MobaXterm SFTP 文件拖入；
MobaXterm 24.2 的实际跨窗口拖动仍待实测。
结构与序列菜单新增“在文件夹中显示”和“复制文件路径”。
全局关闭浏览器自带右键菜单，保留 Facet 自己的右键菜单。

拖入与菜单修正：
单选或未选择时，右键菜单处理点击条目；多选时处理已选集合。
本地拖入优先记录原路径，避免不必要的副本。
修正 MobaXterm 只提供 Move/Link 时显示禁止拖入的问题；临时下载文件
直接读取 MobaXterm 提供的路径，不再另存 Facet 副本。

连续拖入按批次先后顺序加入，取消接收进度浮窗和忙碌重试提示。
