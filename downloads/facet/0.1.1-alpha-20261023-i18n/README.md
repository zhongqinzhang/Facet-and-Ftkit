## Installation and first use

Run the EXE, choose a language and finish setup. One application core includes Simplified Chinese and English. Later toolbar language changes take effect after restart.

This version applies a new installer choice once on the next launch, then retains manual preferences. Completing another installation or repair applies the newly selected setup language.
