本手册按界面名称介绍入口和操作。图标按钮可悬停查看提示；
“→”表示依次点击，Advanced 表示展开高级设置。
在文本编辑器中按 Ctrl+F，可搜索功能名、按钮文字或章节编号。
文中长度单位 Å 为埃，1 Å = 0.1 nm；角度单位为 °。
磁矩单位 μB 为玻尔磁子；速度单位 Å/fs 中，fs 为飞秒（10⁻¹⁵ 秒）。

00  安装与五分钟上手
========================

0.1 安装或更新

本版适用于 Windows x64，版本为 Facet 0.1.1 Alpha（2026-10-22）。
  1. 更新前先保存项目，并关闭正在运行的 Facet。
  2. 双击 Facet Setup，选择简体中文或 English，再按安装向导选择位置。
     安装包内是一套程序核心和两套语言资源；本次安装后首次启动使用所选语言。
     顶栏语言选择可改为“跟随系统”、简体中文或 English，下次启动生效。
     安装选择只应用一次，此后手动设置保持有效；重新安装时采用新选择。
     切换语言不修改项目或科学数据。
     若选择 D:\ 等盘符根目录，安装器会使用其下的 Facet 文件夹。
  3. Windows 需要 Microsoft Edge WebView2 145 或更新版本。
     缺少或版本过低时，安装程序需要联网补装；环境就绪后可离线使用。
  4. 从开始菜单、桌面入口或安装目录中的 Facet.exe 启动。

安装目录中的“使用手册”快捷方式指向 docs\zh-CN\user-guide.txt；
更新内容见同目录的 release-notes.txt。官方主题副本在 presets\themes。
项目保存在你自行选择的位置；升级前建议另行备份项目、关联体数据和预设。
自动恢复副本的位置及使用方式见第 16 章。

0.2 从结构文件到第一张图

以 ABACUS 的 STRU_300K 或 VASP 的 CONTCAR 为例：
  1. 在欢迎页点“打开文件或项目”，选择结构文件。
     已进入工作区时，用 File → 打开…，也可将文件拖入窗口。
  2. 在左上项目树中选中结构。右键拖动旋转，中键拖动平移，滚轮缩放。
     点击顶部“适配视图 (Fit)”，或在普通视图区按空格，重新取景。
  3. 在左侧“显示”调整原子、键和晶胞框；在“外观”中选择材质。
     想用二维画法，选择“2D玻璃球”；其他 3D 材质使用三维画法。
  4. 若有磁矩或速度，在右侧矢量列表中选择相应组。
     调整“显示长度”或点击眼睛控制显隐，原始科学数值不会随之改变。
  5. 按 Ctrl+S 保存为 .facetproj，便于下次继续工作。
  6. 用 File → 导出图片 → PNG，设置尺寸和背景后保存图片。

.facetproj 是可继续编辑的项目；PNG 是用于报告或论文的图片，两者用途不同。
体数据项目还可能依赖外部 CHGCAR/PARCHG 等文件，分享时需一并提供。
打开时出现提示先阅读其内容：红色错误表示该文件未成功导入；
“附加参数已保留为原始导入记录”表示结构已打开，但这些参数未作为
Facet 当前可编辑的计算约束生效。ABACUS 的详细规则见 2.4。


01  功能与入口速查
====================

Facet 提供多套原子与键样式、元素配色和材质预设，可以直接选用，
也可以继续调整。配色板、材质和主题支持保存与导入导出，
便于逐步积累自己的出图方案，或让实验室成员复用同一套设置。

按要做的事情找入口：

  调整原子与键：
    显示 → Atom & Bond。
    选择球、球棍、棍、线、点、CPK、多面体等样式；
    调整原子大小、键粗细、透明度，计算成键或添加手工键。（第 3 章）

  调整元素颜色与局部样式：
    元素 → 配色板 / ELEMENTS / 选中原子。
    切换配色板，按元素或按所选原子改色、改半径、显示序号；
    保存、导入和导出个人配色板。（第 3 章）

  调整质感与整套外观：
    外观 → 材质 / 光照；顶部“主题与外观”。
    选择材质与 2D玻璃球，微调光照和效果；
    把常用设置保存成可反复使用的材质或主题。（第 4、5 章）

  调整晶胞显示与视角：
    显示 → Lattice；顶部 a、b、c 和“适配视图 (Fit)”。
    设置周期显示范围、原子补全、晶胞框和观察方向。（第 6 章）

  选择和组织原子：
    顶部“选择 → 富选择”；元素 → 选择集。
    按元素、z 层、配位数、球形邻域筛选，并把常用选择保存成组。
    （第 7 章）

  突出局部区域或分析局域电荷：
    顶部“选择 → 局域盒”。
    调节盒内外透明度、叠加颜色，分析区域体积、电荷和偶极矩。
    （第 8 章）

  测量：
    顶部测量下拉；显示 → Measurement。
    距离、角度、二面角、分量距离，可选择显示哪些分量。（第 9 章）

  编辑和构建结构：
    顶部“加原子”、移动/旋转按钮、“结构工具”。
    添加、删除、替换、移动和复制原子；菜单包含：
    对称性、晶格参数…、构建超胞…、切割表面…、添加真空层…、
    构建界面…、对齐原子…、设置原子约束…。（第 10 章）

  查看体数据和矢量：
    显示 → Isosurface / Vector；顶部“新建矢量”。
    电荷密度或静电势的等值面、截面，以及原子附着或自由矢量。
    （第 11、12 章）

  播放结构序列、导出 GIF：
    打开序列后使用播放栏，也可从项目条目创建结构序列。（第 13 章）

  查看声子和 STM：
    声子播放栏与声子谱用于切换模式、频率单位和播放动画。（第 17 章）
    Isosurface 中的 STM 用于完整电荷密度的恒高/恒流计算与数据导出。（第 18 章）

  保存和导出：
    File → 保存项目 / 另存为… / 导出图片 / 导出结构。
    项目管理见第 2 章，导出格式见第 14 章。


02  File：打开文件与管理项目
==============================

2.1 打开文件

入口：File → 打开…；欢迎页也提供打开入口。

想先进入空白工作区，在欢迎页点击“新建空项目”。
新项目名为“未命名项目”，不包含任何结构；之后可打开或拖入结构文件。
首次保存时再选择项目文件名和位置。

常用文件：
  - Facet 项目：.facetproj。
  - Facet 静态结构、结构序列或声子包：.facet。
  - QE 声子：scf.in、scf.out、matdyn.modes，或包含它们的 ZIP。
  - 晶体结构：CIF、VASP 的 POSCAR/CONTCAR、XYZ/extXYZ、MSI 结构文件。
  - ABACUS 结构：STRU、.stru、STRU_300K 等内容完整的 STRU 文件（见 2.4）。
  - VASP 结构序列：XDATCAR。
  - VASP 电荷密度体数据：CHGCAR、CHG、PARCHG。

选择文件并打开后，在左上项目树中点击要查看的结构。
普通结构文件可以多选导入当前项目；打开 .facetproj 会切换整个项目。
普通 XYZ 按单帧结构读取；播放多帧数据请使用受支持的序列格式。
.facet 根据包内记录的对象类型区分静态结构、序列和声子，不按帧数猜测。
因此一帧序列仍有序列播放栏；新版 ftkit 201 生成静态磁结构，没有轨迹播放栏。
202 生成包含多个独立静态磁结构的项目，条目名对应计算目录名。

切换项目时，若新文件校验或读取失败，当前项目会保留并显示错误；
点击“不保存”只是允许放弃修改以切换，不会在新文件读入失败时先清空旧项目。
若提示“project schema version 20 requires a newer application”，
请用本版或更新的 Facet 打开；不要改文件中的版本号来强行加载。

从 MobaXterm 拖入远程文件：
  1. 在 MobaXterm 左侧 SFTP 文件列表中选中文件。
  2. 拖到 Facet 欢迎页或主窗口，等待文件接收完成。
  3. Facet 直接读取 MobaXterm 提供的临时文件。

支持单个或多个文件，不支持拖入文件夹。远程文件不会被修改。
前一批尚未处理完时，可以继续拖入；后续批次会按拖入顺序加入，不显示接收进度浮窗。
Facet 不再另存一份副本到 imports；结构编辑不会同步回服务器。
重复拖入仍可能增加项目条目。MobaXterm 清理临时文件后，已读入的普通
结构仍可查看和保存；文件定位或依赖外部体数据的项目可能需要重新指定来源。

2.2 项目树

项目树用于管理多份结构、序列、声子和关联体数据。

  - 点击条目切换当前查看对象。
  - Ctrl 点击可多选，Shift 点击可选择连续条目。
  - 通过条目的右键菜单重命名、组织分组或移除条目。
  - 拖动项目区域下方的分隔条可调整它的高度；双击可恢复自动高度。

选中一个结构或序列后，右键菜单提供：
  - 在文件夹中显示：打开 Windows 文件资源管理器并选中来源文件。
  - 复制文件路径：复制完整路径，可用 Ctrl+V 粘贴到其他地方。
例如来源为 D:\计算结果\Si\CONTCAR，前一项会打开 Si 文件夹并选中
CONTCAR；后一项会复制 D:\计算结果\Si\CONTCAR 这段文字。

单选或未选择时，右键菜单操作点击的条目：选中 A 后右键 B，操作 B。
多选时菜单操作已选条目集合；多选时不显示这两个文件路径操作。
没有来源文件的条目，这两项不可用。源文件已移动或删除时，
仍可复制记录的路径，但“在文件夹中显示”会提示找不到文件。
MobaXterm 拖入文件对应它提供的临时文件位置；普通本地文件对应原路径。

项目树分组用于整理文件条目。
“元素 → 选择集”用于保存一个结构里的原子/键选择，操作见第 7 章。

2.3 保存、另存和最近项目

File → 保存项目，或 Ctrl+S：
保存为 .facetproj，保留项目组织、结构、序列、声子、视图和相关显示设置。
首次保存时选择文件位置。

File → 另存为…：
把当前项目另存一份，适合保留修改前版本或创建分支方案。

File → 新建项目：
开始一个新的项目。当前项目有未保存修改时，按提示处理。

File → 最近项目：
重新打开最近使用的项目；移除历史记录不删除磁盘上的项目文件。

Ctrl+R：
关闭当前项目并返回起始界面。它不是刷新页面的快捷键。

需要继续编辑整套工作时保存 .facetproj；
只交换某一结构、序列或声子数据时，可使用 .facet，见 14.2。
项目中的体数据可能引用外部文件，分享时一起带上，见 11.5。


2.4 ABACUS STRU：磁矩、速度和附加参数

本版可读取内容完整的 STRU、.stru、STRU_300K、STRU_ION_D12 等结构文件。
文件名不必固定为 STRU；Facet 会检查内容，再由 STRU 解析器校验。
需要完整的 ATOMIC_SPECIES、LATTICE_CONSTANT、LATTICE_VECTORS
和 ATOMIC_POSITIONS，不能只提供依赖外部 INPUT 才能确定晶胞的片段。

坐标支持 Direct、Cartesian、Cartesian_au、Cartesian_angstrom，
以及 Cartesian_angstrom_center_xy/xz/yz/xyz 居中模式。
支持 # 与 // 注释、E/e/D/d 科学计数法；例如 1D-4 与 1e-4 表示同一个数。

可选原子属性：
  - m 或省略 m 的三个 0/1 标记：三个方向的原子可动约束。
  - mag / magmom：一个标量或三个磁矩分量，单位 μB。
    标量可配合 angle1、angle2；三分量磁矩不能同时指定这两个角度。
    这是输入文件给出的初始磁矩，不是 Facet 重新计算的自洽磁矩。
  - v / vel / velocity：三个笛卡尔速度分量。输入采用 ABACUS 原子单位，
    导入时换算为 Å/fs；1 原子速度单位约等于 21.8769 Å/fs。
    速度单位不随 Direct/Cartesian 坐标模式或晶格常数改变。

这些已知属性可以混排；同一属性及其别名不能重复。
例如以下原子行表示分数坐标为 (0, 0, 0)、允许移动、具有速度和初始磁矩：
  0 0 0 m 1 1 1 v 1D-4 0 0 mag 3
其 x 方向速度约为 0.00218769 Å/fs，初始磁矩为沿 z 的 3 μB。
磁矩和速度会进入各自的矢量组；箭头尺寸规则见 12.4。

sc / constrain（自旋约束）、lambda 等暂不能在 Facet 中编辑的参数，
以及可识别的其他附加参数片段，会保留为原始导入记录并显示提示。
物种质量、赝势、轨道、描述符和 PAW 路径等也作为来源信息保留；
Facet 不会打开这些关联文件执行计算。

“保留为原始导入记录”表示记住导入时的文本及其来源，并随项目保存、
重开和恢复数据保留。它不表示已经施加这些自旋约束，也不会在后续
编辑结构时自动更新成新的 ABACUS 计算输入。本版不提供 STRU 回写。
要保留完整工作状态，请保存 .facetproj，并自行保留原始 STRU。

缺少晶格、坐标或数值非法、已知参数分量数量错误等情况仍会阻止导入。
欢迎页和普通 2D/3D 工作区都会显示错误信息，包括可用的文件名与行号。
普通工作区的红色提示可点击“×”关闭；关闭提示不会修复或导入该文件。
修正源文件后重新打开即可；导入失败时，已有项目内容保留。


03  Atom & Bond、配色板与 ELEMENTS：原子与键
================================================

3.1 原子样式与键的外观

入口：左侧“显示 → Atom & Bond”。

先选择“原子样式”：
  - 球：用球体观察原子位置。
  - 球棍：同时观察原子和连接关系。
  - 棍、线：以连接关系为主，减少球体遮挡。
  - 点：用简洁标记查看较密集的原子分布。
  - CPK：用较饱满的空间填充表现观察原子占据的外形。
  - 多面体：围绕指定中心显示配位多面体，操作见 3.6。
  - 不显示：隐藏原子表现。

接着调整“原子大小”“显示键”“键半径”。
展开 Advanced，可调整“原子透明度”“键透明度”和成键条件。

有原子或键被选中时，相关控件可只修改选中对象；
例如“原子大小”会变成“大小倍率”，选中键会出现“整键颜色”。
要调整全局外观，先清除选择。出现“混合”表示所选对象的值不同，
此时输入一个新值会把对应属性设为一致。

显示大小、颜色和透明度用于调整画面，不修改原子坐标。
原子与键共用材质外观，材质预设的使用见第 4 章。

3.2 选择配色板

入口：左侧“元素 → 配色板”。

内置配色板有：
  柔和、明亮均衡、低饱和度、高对比、高饱和度、深色克制、单色灰。

直接从下拉菜单切换，观察当前结构的元素区分度，再选择合适的一套。
想先得到柔和效果可从“柔和”或“低饱和度”开始；
想突出不同元素可尝试“高对比”或“高饱和度”。

配色板负责元素颜色；材质负责表面质感。二者可以组合使用，
例如保持同一配色，只切换“哑光”和“柔亮树脂”来比较质感。

3.3 ELEMENTS 与选中原子：改色、半径、序号和可见性

入口：左侧“元素”。

“ELEMENTS”始终列出当前结构中的元素。
在对应行可以：
  - 点击色块修改该元素的颜色。
  - 修改“半径 (Å)”。
  - 点击序号图标控制原子序号。
  - 使用“可见”开关显示或隐藏该元素。

选中原子后，会出现“选中原子 · N”，N 是选中原子数量。
在这个区域修改，只作用于选择中的对应元素原子及其周期副本。
例如只想把界面附近的一部分 O 改成红色：
先选中这些 O，再在“选中原子”中改色，无须修改全部 O。

局部颜色优先于该元素的全局颜色，所以切换配色板后，
手动设置过局部颜色的原子可能保持原色。需要统一时，
打开对应颜色控件，点击“默认色（点击恢复）”，或重新设定颜色。

3.4 保存、导入和导出配色板

调好 ELEMENTS 中的元素颜色后，回到“配色板”：

  1. 点击“保存”旁的下拉按钮，选择“保存为新配色板”。
  2. 输入名称，例如“界面图配色”，点击“保存”。
  3. 以后直接从配色板下拉列表选用。
  4. 修改自定义配色板后，点击“保存”更新它；
     想保留旧版本时，再“保存为新配色板”。

内置配色板的修改会保存为自定义副本。
“导出”生成配色板 JSON 文件；另一台电脑点击“导入”即可加入自己的库。
名称冲突时，可以按提示覆盖已有自定义配色板或保存副本。
列表支持整理顺序、重命名自定义项和隐藏内置项；
“恢复默认列表”可找回内置项。

配色板保存元素颜色；原子半径、样式、局部着色等应随项目保存，
通用的整套外观可另存为主题，见第 5 章。
这样可以分别积累配色库和完整出图方案，不必每次重新调色。

3.5 计算成键、元素对规则与手工键

入口：显示 → Atom & Bond → Advanced；顶部“计算成键”。

先设置“成键判据”：
  - 共价半径比例：用两元素共价半径之和作为基准，
    “比例 From / To”设定接受的距离比例范围。
  - 绝对距离：“距离 From Å / To Å”直接设定最短、最长距离。
  - 指定元素对的距离规则：单独调整某一对元素的成键范围。

在同一面板的“成键元素”中，可选“全部元素”或“自定义元素对”。
自定义时只计算列出的组合，并仍须满足上面的距离判据：
例如只列 C–O，就不会自动生成 C–C；C–O 与 O–C 是同一项。
自定义列表为空时不生成自动键，手工键仍保留。切回“全部元素”会保留
备用的自定义列表。换结构后不存在的组合会显示“未匹配”。
成键元素改变实际自动成键计算，不等同于仅隐藏某些键。

设好后点击“计算成键”，检查连接和跨晶胞边界的表现。
成键规则同时影响邻居补全、配位数筛选和多面体。

需要单独连接两个原子时，先选中两个目标原子，再在属性入口
使用“添加手工键”。选中已有键可以查看端点、长度和周期偏移，
并修改键外观或删除。跨胞键要选对两个端点的周期位置。

手工键和对自动键的编辑可随项目或 .facet 保存。
自动成键依据几何规则；测量实际距离请使用第 9 章的测量工具。

3.6 多面体

  1. 在原子与键区域展开“配位多面体”，点击“＋ 新建”创建分组。
  2. 选择中心元素，或用“使用当前选择”记录已选原子/周期实例作为中心。
  3. 选择配体元素或“最近邻元素”；配位方式可选“已有键”或“按距离”。
  4. 按距离时设置最短和最长距离；按已有键时确认成键数据可用。
  5. 每组独立控制显示、面色、棱线、透明度和高光；“跟随中心”使用中心原子颜色。
  6. 分组菜单可重命名、删除分组，也可删除当前选中的多面体并恢复已删除项。

多面体为显示表示，不移动源原子。若配位不符合预期，检查中心、配体和配位规则。


04  外观：材质、光照与效果预设
================================

4.1 先选材质预设

入口：左侧“外观 → 材质 → 预设”。

内置选择包括：
  - 哑光：较柔和的表面表现。
  - 柔亮树脂：突出圆润亮区和球体质感。
  - 釉面陶瓷：带有釉面光泽。
  - 金属：突出金属反射。
  - 玻璃：具有透射效果。
  - 出版插画：偏插画式的明暗表现。
  - 柔彩：柔和的彩色球体表现。
  - 2D玻璃球：切换到二维投影表现。

选择预设后可以直接使用，也可以展开 Advanced 继续调节。
带推荐光照的材质会同时应用配套光照；
如果要保留已调好的灯光，在该预设的操作菜单中选择“仅应用材质”。

“2D玻璃球”仍可旋转观察三维结构，只是采用另一种绘制方式。
切回任一 3D 材质即可恢复对应的三维表现；
2D 状态下不使用 3D 材质预设的保存操作，整套效果可保存成主题。

4.2 常用材质参数怎么调

入口：外观 → 材质 → Advanced。

先改一个参数，观察画面，再继续微调：
  - 粗糙度：控制高光的锐利或柔散程度。
  - 金属度、环境反射：调整金属感和环境反射表现。
  - 镜面强度、镜面颜色：调整表面高光。
  - 清漆、清漆粗糙度：调整表层光泽。
  - 光泽强度、光泽粗糙度、光泽颜色：调整柔软的光泽层。
  - 折射率 IOR、透射强度：调整玻璃类质感。
    启用透射后，还可调厚度、衰减颜色、衰减距离和色散。
  - 启用球面塑形、插画亮区强度/尺寸、半球暗面强度：
    调整球体亮区和暗面的塑形效果。
  - 彩色边缘光、边缘光指数、通透感、边缘暗化：
    调整边缘与轮廓处的明暗表现。

可调参数随当前材质和 2D/3D 模式变化，以界面启用的项目为准。
刚开始可只调整“粗糙度”和亮区，再保存满意的版本。

4.3 光照

入口：外观 → 光照。

“开启方式”可以启用“自定义光源”或“影棚反射”。
先用“环境光”调整体亮度，再调直接光或反射，避免同时改太多项。

自定义光源：
  - 可调整光源名称、强度、颜色或色温。
  - “跟随相机”让灯光方向随视角变化；“世界固定”把方向固定在场景中。
  - 展开光源设置，可调方向、点光、聚光等类型及各自参数。

影棚反射：
  - “反射形状”可选圆形、长条、抛光。
  - 用强度、尺寸和“高光水平 / 高光垂直”调整反射亮区。
  - 用“中性填充”和“影棚曝光”调整暗部与整体反射亮度。

想让同一材质在下次使用时保持这套光照，保存材质时勾选
“同时保存当前光照（推荐）”。

4.4 AO、描边与原子辉光

入口：外观中的对应折叠区。

“AO / 接触阴影”：
控制原子相邻、接触处的暗部层次；可调整 AO 强度、半径和阴影强度。
AO 即环境光遮蔽。

“勾边 / 描边”：
启用外缘描边后，调粗细、深度和颜色，让轮廓更容易分辨。

“原子辉光”：
启用辉光后调强度、大小；可“跟随原子色”，也可指定辉光色。
有选择时会显示“选中辉光”，便于只突出部分原子。
边缘模糊及其强度也在此调整。

这些效果属于外观设置。使用整体主题保存常用组合，见第 5 章。

4.5 保存并积累自己的材质

  1. 在预设基础上调好材质和光照。
  2. 点击“保存”旁下拉，选择“保存为新材质预设”。
  3. 输入名称，决定是否“同时保存当前光照（推荐）”，点击“保存”。
  4. 下次从材质列表直接选用；继续修改后可“保存”更新自定义项，
     或再次保存为新预设保留另一版。
  5. 点击“导出”保存材质 JSON；在另一台电脑点击“导入”复用。

在内置材质上点击“保存”会创建自定义副本。
列表可重命名、整理顺序；自定义项可删除，内置项可隐藏，
并可通过“恢复默认列表”找回。
切换时出现未保存修改提示，可先保存、另存副本，或放弃本次修改。

材质预设保存材质及可选光照。若还想一起保存原子样式、配色、
背景与其他通用显示设置，使用“主题与外观”。


05  主题与外观：保存、复用和分享整套设置
==========================================

5.1 选择主题与调整界面

入口：顶部“主题与外观”。

内置主题有“经典”“2D玻璃球”和“柔彩”。选中后应用整套设置，
再根据需要修改原子与键样式、配色、材质、光照等。

此面板还可以直接调整背景、文字颜色、主题色、
原子高亮、键高亮、界面字号和暗色主题。
背景旁的“主题 / 白 / 黑”便于快速切换背景方案。

主题用于把通用显示设置与界面外观组合起来。
例如为白底报告图、深底演示图分别保存主题，之后一选即可复用，
不必依次重调原子大小、颜色、灯光和背景。

侧栏宽度、当前页签、滚动位置和面板展开状态会自动记住。
切换主题、打开其他材料或重启软件时，继续沿用你的操作习惯。

5.2 新建、更新和还原主题

“原子补全”的选择也随主题保存。每套主题记录自己的模式，
切换、还原或导入主题时恢复对应选择，并作为新导入结构的初始模式。
例如主题 A 用“仅显示范围内”，主题 B 用“补齐所有原子的邻居”，
切换时分别恢复；不会固定为某一种模式。
补全中心、原子和组引用仍按各结构管理，已有项目按自身保存状态恢复。

保存一套新方案：
  1. 在各面板中调好当前外观。
  2. 打开“主题与外观”，点击“＋新建”。
  3. 输入一个便于识别的名称并确认。

更新已有方案：
  自定义主题调整后点击“保存”，更新这套主题。
  内置主题点击“保存”时，输入名称，保存成自己的新主题。
  需要保留原方案时，也可用“＋新建”保存另一套。

查看当前状态：
  “经典”表示当前通用外观与经典预设一致。
  “经典·已修改”表示源自经典，但保存或调整了不同的样式参数。
  “已修改”只表示与预设不同；项目即使已保存，也可以显示这个状态。
  切换材料时显示各材料自己的主题，不会把上一材料的主题改掉。
  如果文件没有可识别的主题来源，显示“自定义”，可命名保存为主题。

还原预设：
  点击“还原”，恢复名称所指主题的预设参数。
  例如“经典·已修改”还原后变成“经典”；Ctrl+Z 可撤销这次还原。
  无法识别主题来源的“自定义”没有可还原的预设，此时按钮不可用。
  切换主题遇到保存提示时，按要保留的版本选择处理方式。

5.3 整理、导入和导出主题

主题列表可拖动排序；通过条目的菜单重命名或删除自定义主题。
内置主题可隐藏，之后可用“恢复内置主题”找回。

点击“导出”把当前外观参数生成主题文件，包括尚未存入预设的调整；
在另一台电脑点击“导入…”载入。
分享主题适合统一实验室的配色、球棍比例、材质和背景，
也方便自己长期维护不同用途的外观方案。

配色板、材质和整套主题可以分别积累：
只改元素色时复用配色板，只改质感时复用材质，
需要整体切换时复用主题。

5.4 “应用于本项目”与保存项目

主题面板中的“保存”：保存个人主题，以后可在其他项目中选用。

“应用于本项目”：把当前整套主题设置应用到本项目内的各个结构，
并把主题纳入项目状态，之后按 Ctrl+S 保存。此操作会统一外观，清除原有逐元素、
逐原子和逐键的局部样式覆盖；已单独调色的结构也会受到影响。
需要保留各结构不同的局部着色时，直接保存项目即可。

File → 保存项目：
保存当前项目的具体工作状态，包括结构、局部外观、局域盒和测量等。
保存项目不覆盖主题预设，也不会清除“·已修改”。完成一套图后，
既可保存项目继续编辑，
也可另存主题，把可复用的通用设置留给下次使用。

06  Lattice、相机与视图操作
============================

6.1 旋转、平移、缩放和适配

在主视图区：
  - 右键拖动：旋转视角。
  - 中键拖动：平移视图。
  - 滚轮：缩放。
  - 点击“适配视图 (Fit)”或按空格：让结构适合当前窗口。

顶部 a、b、c 按钮分别沿对应晶轴正视。
键盘 a、b、c 可切换晶轴视角，x、y、z 可切换笛卡尔轴视角。
“推荐视角 / 标准晶体取向”使用顶部按钮；目前没有专用快捷键。

Fit 只调整取景，不改变原子坐标或磁矩、速度数值。
输入框、菜单和对话框可能接管空格；结束这些操作后再使用视图区快捷键。

鼠标位于数值输入框上时，滚轮可能调节参数；
要缩放视图，先将鼠标移回画面。

6.2 Lattice：晶胞框与显示范围

入口：左侧“显示 → Lattice”。

“晶胞框”可选“不显示”“单个晶胞”“所有晶胞”。
沿 a、b、c 设置显示范围，例如 a 从 0 到 2，可查看沿 a 相邻的周期晶胞。

展开 Advanced，可设置：
  - 坐标轴：隐藏、abc 或 xyz；默认字号 22 px，可在 6–48 px 间调整。
    未设置字号的主题和旧文件采用默认值；文件中已保存的字号保持原样。
  - 晶胞框的线型、颜色、线宽、不透明度和深度衰减。
  - 原子归位胞内、补全边界原子等显示选项。

显示范围使用分数坐标：沿一个晶格矢量走完整一格，对应增加 1。
晶轴 a、b、c 在斜晶胞中不一定互相垂直，也不一定与屏幕方向一致。

这里增加的是显示出来的周期副本，源结构的原子数不变。
需要真正增加晶胞和原子数据时，使用“构建超胞”，见 10.5。

6.3 原子补全

入口：显示 → Atom & Bond → 原子补全。
可选择：
  - 仅显示范围内：按所设 a/b/c 范围显示。
  - 补齐指定原子的直接邻居：设置中心元素、原子或组，补出直接邻居。
  - 补齐所有原子的直接邻居：补出范围内所有原子的直接邻居。
  - 只补完整分子：对自动识别的有限分子补齐相连原子。
  - 补齐分子与完整层厚度：在补完整分子的基础上保留相交层的完整厚度，
    不额外向面内扩出一圈邻居。

例如希望边界处的配位多面体完整，可以选择补齐指定原子的直接邻居。
补全依赖自动成键规则；出现多补或漏补时，先检查成键元素和距离条件。
橙色三角形表示有需要注意的分析情况，点击或悬停可查看具体原因。
不能可靠识别的部分会保留在显示范围内；自动分子识别并非普适化学判定。
这些选项只影响周期显示，实际增加原子和晶胞请使用“构建超胞”。

6.4 相机与画质

入口：外观 → 相机。

“投影”可选“透视”或“正交”。
透视有近大远小效果；正交适合比较方向与比例。
还可以调整视场角、旋转步长、旋转速度、缩放速度、
前后淡出及淡出范围。

视口画质提供：
  - 自适应高画质：交互时兼顾速度，停止后继续精修。
  - 始终高精度：持续使用较高显示精度。
  - 流畅：适合先调整较大结构的视角。

2D/3D 的切换见 4.1；图片导出格式见 14.1。


07  选择：普通选择、富选择与组
================================

7.1 普通选择

退出测量、局域盒框选等工具后，在主视图区操作：

  - 左键点击原子或键：选中对象。
  - 左键拖框：选择框内对象。
  - Shift 配合选择：追加到已有选择。
  - Ctrl 配合选择：切换对象的选中状态。
  - Alt 双击原子：按同元素扩展选择。
  - Ctrl 双击原子：按所在的组选择。
  - Ctrl+A：全选当前结构中的原子。
  - Esc：退出当前交互或清除选择。

选中后可改样式、改色、移动、删除，或保存成组。
选择周期副本时，编辑通常作用于对应源原子；它在其他晶胞中的副本
也会随之更新。

7.2 富选择

入口：顶部“选择”的下拉菜单 → 富选择。

先选“组合模式”：
  - 替换：用本次结果取代原来的选择。
  - 追加：把本次结果加入原来的选择。
  - 交集：只保留同时满足当前选择和本次条件的原子。

再使用对应条件右侧的“选中”：
  - 按元素：可选择一种或多种元素。
  - z 层：输入上下限，可选“分数”或“笛卡尔 Å”。
    “分数”按第三个分数坐标筛选；“笛卡尔 Å”按全局 z 坐标筛选。
  - 配位数：输入最小、最大配位数，筛选指定邻居数量的原子。
  - 选择球内：先选中心原子，再输入半径，单位 Å。
    有多个中心时，选择落在任一中心球形邻域内的原子。

底部“反选”用于切换已选和未选范围；
“扩展同元素”用于选出与当前所选原子元素相同的原子。
配位数结果依赖当前成键规则。

例如只选某一层中的 O：
  1. 用“替换”，在“按元素”选 O，再点“选中”。
  2. 把组合模式改成“交集”。
  3. 在“z 层”输入所需范围，再点“选中”。
  4. 检查高亮结果，然后改色、设置约束或保存为组。

7.3 组：保存常用的原子和键选择

创建：
  先选好原子/键，打开选择的右键菜单，点击“保存为新组”，输入名称。
  到左侧“元素 → 选择集”查看。选择集条目会显示原子数和键数。

使用：
  - 双击组条目：选中该组。
  - Shift 双击：把该组追加到当前选择。

修改组成员：
  先在视图中选好要处理的对象，再打开目标组菜单。
  “加入当前选择”把当前选中对象加入这个组；
  “移出当前选择”把当前选中对象从这个组中移除。
  选择右键菜单中的“从所有组移出”可移除所选对象的全部组归属。

管理：
  可重命名、删除和调整组的顺序。
  删除组只移除这份选择记录，不删除原子或键。
  组随项目及相应 .facet 结构包保存。

例如把上下两层分别保存为“上层”“下层”，之后双击组即可重新选择，
用于整层改色、移动、设置约束或进一步筛选。


08  局域盒：局部透明度、颜色蒙版与电荷分析
============================================

8.1 创建局域盒

入口：顶部“选择 → 局域盒”，也可点击“选择”的局域盒主按钮。

  1. 把结构转到便于圈定区域的方向。
  2. 启用“局域盒”，在画面中用左键拖出矩形。
  3. 松开后，在“局域区域”列表选中新建的盒子。
  4. 在属性面板调“盒内效果”“盒外效果”和空间尺寸。

局域盒有宽、高、深，屏幕矩形只是它的投影。
旋转视角检查深度，必要时在 Advanced 输入准确尺寸。
Esc 可取消尚未完成的框选。

8.2 盒内效果与盒外效果

局域盒可给盒内或盒外区域调透明度、叠加颜色，形成局部蒙版。
结构和电荷显示可以共同调整，也可以分别调整。

“透明度”：
  1 表示保持已有透明度，0 表示完全透明，中间值进一步淡化。
  它在已有外观上叠乘，不能把本来透明的对象强制恢复成不透明。

“叠加颜色”和叠加强度：
  选择要叠加的颜色，再调强度；0 表示不叠加，数值越大叠色越明显。

“分别调整”：
  分别设置结构和电荷的效果，例如保留原子，只淡化电荷等值面。

“同步调整”：
  让结构和电荷共用设置；已有两组设置不同时，按提示选择以哪组为准。

突出一个局部区域的做法：
  1. 盒内透明度保持 1。
  2. 展开“盒外效果”，把盒外透明度设为 0.15。
  3. 给盒内叠加少量醒目的颜色。
  4. 旋转检查范围，再导出图片。

这些操作只改变局部显示，不删除原子或改写原始电荷数据。

8.3 中心、尺寸与周期重复

入口：选中盒子 → Advanced。

  - 中心：按字段显示的坐标输入。
    u/v/w 是分数坐标；x/y/z 按所示 Å 单位输入。
  - 局部尺寸：设置宽、高、深，单位 Å；数值改尺寸时保持中心不动。
  - 周期重复：用 a、b、c 按钮选择沿哪些晶格方向重复盒子。

也可以在视图中拖动盒子线框移动位置，拖动面上的控制点调整边界。
拖动不便时换个视角，或直接输入数值。
右键拖动仍是旋转视角。

8.4 管理局域区域

列表支持改名、上移、下移和删除。
“方框”控制线框是否显示；“效果”控制局域效果是否启用。
隐藏线框后仍可保留蒙版，适合出图。

多个盒子重叠时，顺序参与效果处理。
效果不符合预期时，可逐个停用检查，再调整顺序。
删除盒子不会删除盒内原子。

8.5 分析此局域

先导入电荷密度，再选中局域盒：
  1. 展开 Advanced，点击“分析此局域”。
  2. 在“局域分析”中设置“统计范围”。
     “显示范围”包含当前显示的周期范围；“单个晶胞”按单胞统计。
  3. 选择“平衡（推荐）”或“高精度”。
  4. 查看结果；需要刷新时点击“重新分析”，结束时点“停止分析”。

结果中：
  - 区域体积：盒子在统计范围内覆盖的体积，单位 Å³。
  - 平均电荷密度、电荷密度范围：该区域的数据均值与最小、最大值。
  - Q+：正值部分积分；Q−：带负号的负值部分积分。
  - Q净：Q+ 与 Q− 之和。电荷单位 e 表示元电荷单位。
  - 正电中心、负电中心：正、负部分各自的加权中心。
  - 偶极矩（相对局域盒中心）：以盒中心为参考的位置加权结果，
    单位 e·Å。可通过相应按钮显示中心位置和偶极方向。
  - Q净中心：在结果可定义时显示。

分析使用所载入的电荷密度数值；差分电荷与总电荷的含义取决于输入文件。
不支持 LOCPOT 静电势文件；电荷积分需要电荷密度数据。
修改盒子、数据或统计范围后，查看更新后的分析结果；
比较两次结果时使用相同范围与精度。

8.6 保存局域盒

保存项目或相应的静态 .facet 包，可保留局域盒及显示设置。
原始体网格是外部资源，分享分析项目时一起带上电荷文件。
如果只需要展示蒙版效果，导出图片即可。


09  测量：距离、角度、二面角与分量距离
========================================

9.1 建立测量

入口：顶部测量按钮旁的下拉菜单。

选择模式，再按提示依次点击原子：
  - 距离：点两个原子，显示长度，单位 Å。
  - 角度：点三个原子，第二个点是夹角顶点，单位 °。
  - 二面角：点四个原子，显示两个平面之间的角度，单位 °。
  - 分量距离：点两个原子，查看从第一个点指向第二个点的位移分量。

跨晶胞测量时，先在 Lattice 中显示目标周期位置，再点选相应原子。
工具会使用选中的具体周期位置，不应把不同周期副本视为同一个测量端点。
Esc 可退出当前测量交互。

9.2 分量距离：选择要标出的方向

完成“分量距离”后，选中这条测量，在属性面板查看三组数据：

“笛卡尔 (Å)”：
  Δx、Δy、Δz 是沿全局 x、y、z 方向的位移，单位 Å。

“分数坐标”：
  Δa、Δb、Δc 是两点分数坐标之差，没有长度单位。
  例如 Δa = 0.5，表示沿 a 的分数坐标相差半个晶格周期。

“晶面法向 (Å)”：
  ΔA*、ΔB*、ΔC* 分别是垂直 bc、ca、ab 晶面方向的位移分量，
  单位 Å。斜晶胞中，晶面法向通常不平行于同名晶轴。

点击某个分量的名称，可选择或取消它在视图中的标注。
例如只保留 Δz 和 Δc，图中就突出这两个方向的信息。
数值区域较窄时可横向滚动查看完整内容。

分量有正负，取决于点选顺序和方向；两点总距离没有方向正负。
需要比较垂直某晶面的高度差时，优先看对应的“晶面法向”分量。

9.3 颜色、字号、显隐与删除

显示 → Measurement：
按距离、角度、二面角、分量距离分别调整标注颜色和字号。

选中已有测量：
可在属性条目中调整颜色、字号，通过眼睛图标显示/隐藏，
通过删除按钮或 Delete 删除所选测量。

测量随项目和支持它的 .facet 数据保存。
原子坐标改变后测量值随端点更新；删除端点或转换结构后需检查标注。


10  加原子与结构工具：编辑、对称性及建模
==========================================

本章按照顶部编辑按钮和“结构工具”菜单介绍操作。
修改对象应为可编辑的静态结构；序列中的科学帧不直接接受这些编辑。
先用 Ctrl+S 保存，完成后也可用 Ctrl+Z 撤销可撤销的结构操作。

10.1 加原子、删除与替换元素

加原子：
  点击顶部“加原子”，选择元素并输入分数坐标，确认加入。

删除：
  选中目标原子，按 Delete。先检查选中数量，避免同时删除其他对象。

替换元素：
  选中原子后，使用底部元素信息中的编辑入口选择新元素；
  多选时按界面列出的元素分组处理。

添加或替换后，检查原子位置和成键。
出现“原子过近”提示时，可用提示定位需要检查的原子。

10.2 坐标、移动、旋转与复制粘贴

精确坐标：
  选中单个源原子，在底部状态栏编辑分数坐标或笛卡尔坐标。
  分数坐标按晶轴表示，笛卡尔坐标按 x/y/z 表示，长度单位 Å。

平移：
  顶部上、下、左、右箭头按屏幕方向移动选中原子；
  “平移步长”控制每次移动的距离，单位 Å。

旋转：
  多选原子后，设置“旋转角度”，再用顺/逆时针按钮旋转。
  精确对齐到某个原子、方向或平面，使用“对齐原子…”，见 10.9。

复制粘贴：
  Ctrl+C 复制选中原子，Ctrl+V 粘贴到当前结构。
  粘贴后检查是否与原位置重叠，再移动到目标位置。

以上操作会修改结构；中键平移、右键旋转视图只改变观察方式。

10.3 对称性

入口：结构工具 → 对称性。

  1. 设置“位置容差 symprec (Å)”；可从默认 0.01 Å 开始。
  2. “角度容差 (°，可选)”可留空使用自动值。
  3. 点击“分析”，查看空间群、Hall、点群、晶系、
     Bravais / Pearson 和对称操作数量。
  4. 展开“Wyckoff 位点”，查看原子的位点标签与位点对称。

位置容差表示允许多大的位置偏差仍视为满足对称关系。
对轻微畸变的结构，适当改变容差再分析，可以比较识别结果。

面板下方：
  - Primitive Cell：转换成原胞。
  - Conventional Cell：转换成常规胞，便于按标准晶胞观察。
  - 对称性校正…：按识别到的对称关系校正结构，阅读确认内容后应用。

“分析”只给出结果；上述转换或校正会修改结构。
转换后核对晶格、原子数和坐标，再保存。
CIF/MSI 的对称性导出见 14.3。

10.4 晶格参数…

入口：结构工具 → 晶格参数…。

输入 a、b、c 长度，以及 α、β、γ 角度，点击“应用晶格参数”。
α、β、γ 分别是 b 与 c、c 与 a、a 与 b 的夹角。

当前操作保持原子笛卡尔位置的周期等价性，并把分数坐标折回晶胞；
不会简单地按原来的分数坐标把所有原子一起拉伸。
若目的是增加薄片外的空白距离，使用“添加真空层…”。

10.5 构建超胞…

入口：结构工具 → 构建超胞…。

输入整数变换矩阵，查看晶胞和预计原子数，确认后点击“替换当前结构”。
例如沿 a 重复 2 次、b 和 c 各 1 次，矩阵三行为：
  2 0 0
  0 1 0
  0 0 1

这会真正生成双倍源原子数，并使晶胞沿 a 加倍；
导出结构得到的也是真实超胞。
矩阵也支持非对角的整数组合，但不能退化成零体积晶胞。

操作会替换当前结构。需要保留原结构时，先导出 .facet 或另存项目。

10.6 切割表面…

入口：结构工具 → 切割表面…。

用于按晶面方向构建表面薄片：
  1. 输入 h、k、l 晶面指数，不能同时为 0。
  2. 设置“薄片厚度”，按需要启用“添加真空层”并设置厚度。
  3. 查看预览中的实际厚度、原子数和层数。
  4. 需要改变暴露的原子层时，调整“表面位置”，或展开
     “表面组成与切割位置”，选择其他“切割位置候选”。
  5. 确认后应用，结果作为新结构加入项目，原结构保留。

实际厚度受原子层位置影响，以预览结果为准。
导出计算用薄片前，旋转检查表面终止、上下两面与真空位置。

10.7 添加真空层…

入口：结构工具 → 添加真空层…。

用于沿 ab 面法向调整薄片之间的真空间隔：
  1. 在“真空层厚度”中输入目标值，按需要启用“结构居中”。
  2. 需要调整插入位置时，展开“真空层位置”，启用“手动指定”，
     调整分数 c 的切分位置。
  3. 手动指定时，可切换“原结构 / 查看结果”检查薄片是否完整。
  4. 应用后更新当前结构。

输入的是最终真空间隔，不是在已有真空上再增加同样的数值。
例如已有约 10 Å 真空，希望最终约 15 Å，应填 15 Å。
斜晶胞中的法向距离也不一定等于 c 轴长度的变化量。

10.8 构建界面…

入口：结构工具 → 构建界面…。

先把上下两层结构都导入同一个项目，再操作：
  1. 选择“上层”“下层”，在“采用晶格”中选择参考层。
  2. “构建方式”选择“直接构建”或“搜索匹配”。
  3. 搜索时设置“mismatch 阈值”“形变阈值”和“总原子数上限”，
     点击“搜索匹配方案”，查看候选尺寸、原子数，再选择候选。
  4. 调整“层间距”“真空层厚度”及 c 方向，观察预览。
  5. 应用后生成新结构，原上下层结构保留。

“直接构建”会按参考晶格适配另一层；
“搜索匹配”用于寻找整数超胞组合，搜索限制只作用于搜索模式。
mismatch 表示匹配前的面内边长失配，形变包括拉伸、压缩和剪切。

层间距按界面法向定义，与两层之间最近的原子间距离不同。
拼接完成后检查上下层位置和原子过近提示。
该工具完成几何建模，不执行能量优化。

10.9 对齐原子…

入口：结构工具 → 对齐原子…。

先选中要移动的原子组，再按目标选择对齐方式：
  - 位置：把锚点对到目标坐标或目标原子。
  - 方向：用两个原子定义方向，对到目标轴或方向。
  - 平面：用三个不共线原子定义平面，对到目标平面/法向。

可使用笛卡尔方向、晶体方向或晶面法向。
检查预览后应用；被选原子作为整体平移/旋转，组内距离保持不变。

10.10 设置原子约束…

入口：结构工具 → 设置原子约束…，也可从选择右键菜单打开。

  1. 选中需要设置的原子。
  2. 调整 Fix X、Fix Y、Fix Z。
  3. 点击“应用到…个原子”。

横线表示该项在当前选择中状态不一致；只修改需要改变的项。
约束作为结构数据保存，用于后续计算格式交换。

结构工具显示预览时，先“应用”或“取消”结束预览，再保存或导出。
可撤销的操作用 Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；
要把撤销后的状态写入磁盘，需再次保存。

11  Isosurface：体数据、等值面与截面
====================================

11.1 导入和选择体数据

入口：左侧“显示 → Isosurface”。

空白时点击“导入 PARCHG / CHGCAR / CHG”，已有数据时用“+ 导入体数据”。
也可通过 File → 打开… 导入受支持的 VASP 体数据文件。

CHGCAR、CHG、PARCHG 用于电荷密度。自定义名称的 VASP 体网格也直接按电荷密度导入，不再弹出物理量选择窗口。
明确识别为 LOCPOT 的文件会被拒绝；请勿将静电势文件改名后作为电荷密度使用。
在数据集列表中选择要调整的一份，用开关控制显隐。
先看面板中的数据类型和单位，再设置等值面数值。

11.2 等值面

等值面把数值相同的位置画成表面：
  1. 在“等值面”区域点击“+ 等值面”。
  2. 输入等值面数值，等待画面生成。
  3. 用每行的眼睛图标控制显隐，删除按钮移除该等值面。
  4. 根据数据设置正、负等值面的颜色和显示开关。
  5. 需要比较不同数值时，可添加多条等值面。

可选择“实体”“线框”“点云”表现。
负等值面只有在数据中存在相应负值且生成了对应表面时才可显示。
等值面数值决定取哪一层表面；颜色、透明度只改变它的画法。

11.3 等值面材质与 Charge Lighting

等值面有独立的材质预设，常用质感包括：
  - 经典光泽：带表面高光的等值面。
  - X-Ray 透视：突出轮廓和透视层次。
  - 柔釉：柔和的表面光泽。

选用后可继续调透明度、轮廓、高光等当前质感支持的参数。
Charge Lighting 用于体数据的光照；可“跟随场景灯光”，
或分别调整电荷的环境光与直接光。

保存一套等值面质感：
  1. 调好当前效果。
  2. 在“保存”旁的菜单中选择“另存为新材质预设…”。
  3. 输入名称，按需要勾选“包含当前 Charge Lighting”，保存。
  4. 下次从等值面材质列表选用；自定义项可继续保存更新。
  5. 用“导出 / 导入”交换等值面材质 JSON 文件。

原子与键材质、等值面材质各自管理，按所在面板保存。

11.4 截面 Sections

入口：Isosurface → 截面 Sections → 添加。

选择截面方式：
  - 简单：晶胞面。选择 AB、BC 或 CA，并调整截面位置。
  - 高级：hkl 平面。输入晶面指数和偏移量。

再调整：
  - 保留侧：法向负侧（下方）或法向正侧（上方）。
  - 色图：蓝–白–红、Viridis、Cividis、Magma、Inferno、Plasma、
    BrBG 或灰阶；可切换反色。
  - 范围：稳健自动、全范围、关于零对称或手动。
  - 不透明度：控制截面的显示浓淡。

差分数据可用“关于零对称”配合发散色图查看正负区域。
要比较多张截面，使用相同的数值范围；必要时选“手动”输入上下限。
通过眼睛图标隐藏截面，删除按钮移除截面。

11.5 保存、外部文件与局域分析

保存项目可记录数据集关联、等值面和截面设置。
原始体网格通常通过外部文件引用；分享项目时，把对应
CHGCAR/PARCHG 等文件一起复制。

文件移动后，按资源定位提示选择原始文件；同名但内容不同的文件
可能不能替代原资源。

若要只调整一个空间区域的显示，或对局部电荷积分，
使用“选择 → 局域盒”，操作见第 8 章。


12  新建矢量与 Vector
=======================

12.1 创建和选择矢量

入口：顶部“新建矢量”。
  1. 要随原子移动时，先选好原子，再使用“附着原子”；
     要指定独立起点时，选“自由箭头”，填写分数坐标起点。
  2. 填写名称，选择颜色。
  3. 在“Cartesian x/y/z”或“晶格 u/v/w”中填写分量，
     按面板标出的单位核对真实长度，再点击“创建”。
  4. 从画面或右侧矢量列表选择单根、数根或整组，继续调整。

同一通道管理同一类矢量，例如磁矩或力。零矢量没有可见箭头。
选中箭头以细轮廓提示，原颜色保留；导出图片/GIF 不包含选择轮廓。
点画面空白清除选择后，右侧保留列表，清空所选对象的详情。

12.2 调整长度、粗度和颜色

选择目标后，在右侧性质栏调整“显示长度”和“粗度”：
  - 显示长度：相对该对象保存基准的百分比。50% 表示显示为一半长。
  - 粗度：单独改变杆和箭头头部的横向尺寸，不改变长度。
  - 复位按钮：回到该对象自己的 100%，不是重新按当前画面计算。
  - 多个目标数值不同会显示“混合”；填入数值后统一对应属性。

改变显示长度、粗度或颜色不会改写磁矩、力或位移的科学值。
例如 4 μB 的磁矩，把显示长度从 100% 改为 50%，磁矩仍为 4 μB。
μB 是玻尔磁子，磁矩常用的单位；它不是箭头在画面中的几何长度。

直接点击矢量列表行左侧的颜色圆点即可改色，不必展开“外观设置”。
  - 已经选中矢量：只修改当前选中的矢量，即使点击的是另一行色点。
  - 没有选中矢量：修改点击行代表的单根或整组。
色盘中会显示本次修改范围。例如先选 A，再点磁矩组色点，只改 A；
点空白清除选择后再点组色点，才修改整组。整组改色保留单根尺寸设置。
一次连续调色可用一次撤销恢复；Esc 取消本次调色。
切换结构或选择目标会关闭原目标的色盘。

12.3 位置、遮挡和其他外观

展开“外观设置”可调整位置、光泽、跟随原子显隐及最小显示模长。
“中段”指原子位于距箭尾约 40% 的位置，箭头穿过原子球；
球体会遮住内部部分，因此可能看上去只露出一截。这不表示磁矩被截断。
希望箭头从球外开始，可选表面位置。也可缩小原子球或调整显示长度。
显隐、周期副本、过滤及通道设置还可在左侧“显示 → Vector”中调整。

12.4 新导入矢量的初始长度与已保存外观

对于首次建立显示基准的矢量组，Facet 使用该组最大的非零模长确定
共同的长度比例，再按同一比例绘制其余箭头。磁矩、力、速度等分别
按各自的组定标；不同物理量之间不能直接比较箭头长度。

例如，同一组一维磁矩为 +1、+2、-4 μB：
  - 最大模长为 4 μB，用它确定初始显示基准。
  - 三根箭头的总长度比例为 1:2:4；负号改变方向，不改变长度比例。
  - 整组“显示长度”改为 50% 后，全部减半，比例仍为 1:2:4。
这是显示缩放，不会把原文件中的磁矩改为 1/4、1/2、-1 μB。
零矢量没有可见箭头；全部为零的组，在首次出现非零值后才能建立基准。

同样的规则用于 ABACUS 的磁矩和速度等新导入矢量。
基准建立后不会因旋转、缩放、切换视图或播放每一帧而反复重新定标。
若分别给单根箭头设置不同长度百分比，画面长度便不再直接代表原始比例；
进行定量对比时应使用同一组的统一显示百分比。

来源文件已经保存外观时，Facet 优先使用该外观：
  - ftkit 201/202 的磁结构保存了自己的尺寸基准；其中新磁矩采用
    公共长度配方的 85%，202 批量项目共用一份比例，便于跨结构比较。
  - 新声子的箭头初始长度采用公共配方的 50%，颜色与附着位置按
    声子设置保留；尺寸由首次显示的振幅建立，播放中不逐帧定标。
    85% / 50% 已包含在相应基准中，因此面板初始仍显示 100%。
  - 旧 .facet / .facetproj 的已保存长度、粗度和颜色优先保留，
    重开不会自动按新规则重新缩短；“恢复 100%”也只是回到该文件的基准。

若旧项目的箭头太长，先选中相应组，调小“显示长度”并保存项目。
如需为普通 STRU 重新建立本版初始基准，可重新导入原始 STRU；
新导入会创建另一个项目条目，不会把旧条目的编辑自动搬过去。
声子箭头的物理含义和振幅关系见第 17 章。


13  结构序列、播放与 GIF
==========================

13.1 打开或创建序列

File → 打开…：
打开 XDATCAR 或内容为序列的 .facet。
ftkit 101 可把 OUTCAR 的逐步结构、力和能量写成 trajectory.facet；
103 可把 NEB 图像组织成 neb-path.facet。弛豫步和 NEB 图像不是物理时间帧。
ftkit 当前不处理 XDATCAR；这不影响 Facet 本体直接读取 XDATCAR。

项目树：
选中多份静态结构，通过相应右键菜单“创建结构序列”；
多项序列/结构也可在可用时“拼接为新序列”。
项目分组的菜单可按组内内容创建序列。

由独立结构创建时，每份结构作为独立快照加入，
不会自动插值生成中间构型。创建后修改原结构也不会同步修改已有序列。

13.2 结构序列播放

激活序列后，在底部“结构序列播放”栏操作：
  - 上一帧、播放/暂停、下一帧。
  - 拖动进度条或输入帧号定位；帧号从 1 开始。
  - 用“倍速”调播放节奏，用“间隔”设置取帧间隔。
  - 展开“播放选项”，设置起始帧、结束帧、正放/倒放。
  - 选择单次、循环或往返。

播放节奏不等于模拟的物理时间步长；
具体时间以输入数据中的时间信息为准。
空格在普通视图区用于适配视图，播放请使用播放按钮。

13.3 周期边界与键连接

“周期边界显示”：
  - 折回原胞：显示位置回到原胞内。
  - 连续运动：显示跨胞的连续路径。
    出现“连续路径：最小镜像推断”时，路径由相邻帧推断；
    帧间隔过大时需结合原始轨迹核对。

“序列键连接”：
  - 动态计算：逐帧更新成键。
  - 固定连接：保持当前段的连接关系，端点仍随原子移动。

13.4 科学通道与曲线

序列帧中的原子、晶格和科学通道来自原始帧数据，
面板会显示“科学数据只读”。可调整显示外观，不能直接改写原帧。

存在矢量通道时，可查看矢量、按模长筛选或着色。
存在标量通道时，可选择它绘制随帧变化的曲线，点击曲线定位帧。
这里只显示或分析已有数据，不会因播放而自动产生源文件没有的能量、力。

13.5 导出 GIF

入口：播放栏 → 导出 GIF。

  1. 设置起始帧、结束帧、取帧间隔。
  2. 设置倍速、方向和循环方式。
  3. 调整输出宽度及取景，检查预计帧数、尺寸和动画时长。
  4. 点击“开始导出”，选择保存位置。
  5. 查看进度；需要中止时使用取消。

要保留可继续查看的序列数据，保存 .facetproj 或序列 .facet。
GIF 用于展示播放结果。


14  File：导出图片与结构
==========================

14.1 导出图片

入口：File → 导出图片 → 选择格式。

  1. 先调好视角、原子与键、配色、材质和背景。
  2. 检查局域盒、等值面、测量和矢量是否按需要显示。
  3. 在导出面板设置尺寸、取景和背景选项。
  4. 确认后选择保存位置，等待导出完成。

格式：
  - PNG、JPEG、WebP：可在 3D 和 2D 中使用。
  - SVG、PDF：在 2D 模式下提供。
  - PNG、WebP、SVG 可使用透明背景；JPEG、PDF 使用实色背景。

需要放进报告或幻灯片时，可先用 PNG。
需要二维矢量格式时，切换“2D玻璃球”后导出 SVG/PDF；
其中电荷等复杂显示可能包含栅格图像，不能把整个文件视为纯矢量。

14.2 导出 .facet

入口：File → 导出结构 → .facet 文件。

静态结构导出结构包，序列导出序列包，声子导出声子包。
声子包保留全部 q 点和模式，见第 17 章。
用于交换当前对象，并保留该格式支持的 Facet 显示和编辑信息。

整个项目及项目树组织应通过“保存项目”保存为 .facetproj。
有外部体数据时，仍需一并提供原始文件。

14.3 导出其他结构格式

入口：File → 导出结构。

“.vasp 文件”：
  导出 VASP 结构，可选择 Direct（分数坐标）或 Cartesian（笛卡尔坐标）。
  导出后核对元素顺序、晶格和约束。

“.cif 文件”和“.msi 文件”：
  可按 P1 完整结构导出，或使用检测到的对称性。
  选择对称性导出时，先核对容差与空间群结果。
  P1 不利用额外空间群操作压缩等价原子。

“.xyz 文件”：
  普通 XYZ 适合原子元素与笛卡尔坐标；
  extXYZ 可携带该导出选项支持的周期晶格等信息。

其他结构格式只保存各自支持的数据。
出现信息丢失提示时，按提示判断是否继续；想保留完整编辑状态，
先保存项目或 .facet。

16  设置保存位置与常见操作问题
================================

16.1 保存到哪里、怎样迁移

项目和导出文件：保存在保存对话框中选择的位置。

主题、配色板、材质等个人预设：
保存在当前 Windows 用户的应用数据中。
换电脑时，在对应面板使用“导出 / 导入”，比直接复制安装目录方便。

需要定位数据时，把以下路径粘贴到资源管理器地址栏：
  本地界面数据：
    %LOCALAPPDATA%\com.facet.app\EBWebView\Default\Local Storage\leveldb
  旧版本曾创建的拖入副本：
    %LOCALAPPDATA%\com.facet.app\imports\v1
    当前本地文件和 MobaXterm 拖入直接读取现有路径，不再另外复制。
    旧副本仍可能被已有项目引用，清理前请先核对。
  最近项目记录：
    %APPDATA%\com.facet.app\project-history.json
  异常恢复副本：
    优先使用程序安装目录中的 recovery 文件夹，例如 D:\Facet\recovery。
    安装目录不可写时，自动改用 %LOCALAPPDATA%\com.facet.app\recovery。
    独立英文版使用 %LOCALAPPDATA%\com.facet.english\recovery。

主题与界面偏好按 Windows 账户保存；recovery 存放异常恢复副本。
自动备份遇到问题时，状态栏只保留“自动备份暂不可用”，点击可查看原因。
软件会在后续备份周期继续尝试，成功后提示消失；手动保存失败仍会立即提示。
备份工作时，复制项目、关联体数据和已导出的预设文件。

16.2 启动与异常恢复

从桌面或开始菜单的 Facet 入口启动。
缺少 WebView2 时，当前 Windows 安装方式需要联网补装；
运行环境就绪后，本地查看、编辑和阅读手册可离线进行。

打开项目时，若有对应的较新且内容不同的备份，可选择：
  - 恢复备份：打开备份内容，检查后主动保存。
  - 取消恢复，打开保存版本：继续打开手动保存的项目。
  - 取消打开：保留当前工作，不打开这个项目。

启动软件本身不会主动弹出恢复提示。未保存的新项目或原文件丢失时，
通过 File 或欢迎页中的“恢复备份…”查找副本。
自动备份至少间隔五分钟；纯旋转、平移视角不会单独触发备份。
有外部体数据时，按提示重新定位资源。

双击安装目录最外层的“使用手册”快捷方式，即可阅读本文。

16.3 遇到显示或操作问题时

结构很小或移到画面外：
  点击“适配视图 (Fit)”或按空格，再检查 Lattice 显示范围。

打开文件后没有看到新结构：
  查看欢迎页内或普通工作区右下角的红色错误信息，按文件名和行号定位。
  “×”只关闭提示；修正文件后需重新打开。ABACUS 支持范围见 2.4。
  导入成功但当前显示的是另一个对象时，在项目树中点击新条目。

ABACUS 提示“附加参数已保留为原始导入记录”：
  结构已经打开。sc/lambda 等参数被保留，但没有作为 Facet 可编辑约束生效。
  保存项目可以保留记录；继续 ABACUS 计算仍应使用自己的原始输入文件。

按空格没有适配视图：
  先结束输入框、下拉菜单或对话框中的操作，再让普通视图区取得焦点；
  也可直接点击顶部“适配视图 (Fit)”。空格不是序列播放键。
  若结构本来已经适合窗口，Fit 可能看不到明显变化。
  本版已修复 3D 磁矩场景中普通重绘取消待执行 Fit 的问题。

部分原子变淡、变色或不见：
  依次检查 ELEMENTS 可见性、选中原子的局部样式、
  Atom & Bond 透明度、局域盒效果和相机前后淡出。

邻居或多面体不完整：
  检查成键距离、元素对规则和 Atom & Bond 中的原子补全。

编辑按钮不可用：
  检查是否在只读序列中，或是否有尚未结束的建模预览。

局域电荷分析不可用：
  检查是否载入电荷密度，以及该数据是否与当前结构关联。
  不支持 LOCPOT；请导入 CHGCAR、CHG 或 PARCHG 电荷密度数据。

换电脑后项目缺少电荷：
  一起复制项目关联的原始体数据，再按提示定位。

大结构旋转较慢：
  先用“流畅”画质，减小周期显示范围，
  隐藏暂时不用的等值面或减少透明叠层，再继续调整视角。

旧磁文件仍显示“1 帧”：
  早期 ftkit 把磁结构写成了单帧序列。用 ftkit 0.1.3 重新运行 201，
  得到明确标记为静态结构的新文件。升级 Facet 不会猜测并改写旧文件类型。

升级后箭头仍然很长：
  已保存外观会优先保留。选中相应矢量组，调小“显示长度”并保存项目。
  新导入原始 STRU 会按每组最大模长建立初始基准；旧项目不会自动重定标。
  恢复 100% 仍使用旧文件自身的基准，详见 12.4。

17  声子：模式、频率单位与动画
================================

17.1 打开声子数据

可用以下入口：
  - 直接打开声子类型的 .facet。
  - 在 Facet 中一起选择 QE 的 scf.in、scf.out、matdyn.modes；
    也可打开包含这些文件的 QE ZIP 包。
  - 在 Linux 上用 ftkit 301 读取 VASP 声子 OUTCAR，或用 302 读取 QE
    结果，再把 phonons.facet 复制到本机打开。ftkit 的完整用法见其中文手册。

matdyn.modes 应来自 matdyn.x 的 flvec 输出，包含本征位移。
只有频率表不能播放动画。VASP 301 对应计算晶胞的单个 Γ 点；
QE 数据可以包含多个 q 点，Facet 会保留文件中的点和模式。

q 是振动在不同晶胞之间的相位变化所对应的波矢；Γ 表示 q = (0,0,0)。
同一个 q 点有许多模式，每个模式描述一种原子一起运动的方式。
不要把模式编号当作轨迹时间帧。

17.2 选择 q 点、模式和频率单位

底部声子播放栏提供 q 点、模式、频率及单位选择。
q 点和模式编号从 1 开始；可用下拉框选择模式，也可在声子谱中选点。
只有一个 q 点时，声子谱显示一条频率竖线，每个模式对应一个点。
频率相同的模式可能重合，可用模式下拉框或图表键盘操作逐个选择。
多个 q 点时显示沿输入点顺序排列的声子色散图。

频率单位可切换：
  - cm⁻¹：光谱中常用的波数。
  - THz：每秒振动次数的单位，1 THz = 10¹² Hz。
  - meV：对应的能量单位，1 meV = 0.001 eV。
切换只改变显示单位和图轴，不重新计算模式，也不改写本征位移。
带负号的频率用于标记虚频；其动画只是模式形状的周期演示，
不能据此认为该不稳定模式具有真实的稳定周期振动。

17.3 播放与位移箭头

选择模式后可播放、暂停、后退、前进，也可拖动相位滑条。
“倍率”调节演示速度；“振幅”调节原子的最大演示位移，单位为 Å。
演示速度不是按真实 THz 在屏幕上实时播放。

勾选“位移箭头”后，箭头表示相对平衡位置的瞬时位移：
  - 经过平衡位置时，位移和箭头长度为零。
  - 到达最大位移处时，箭头最长。
  - 运动到另一侧时，箭头方向反转。
它表示位移，不表示速度。一维例子：原子沿左右方向振动，
在中心处箭头为零；最右端向右，最左端向左。

尺寸基准在初始化时确定；播放经过平衡位置时不会把短箭头重新放大。
把振幅从 0.2 Å 改为 0.4 Å，会同时放大原子运动和位移箭头。
只把矢量“显示长度”改为 50%，只缩短箭头，不改变原子振幅。
要改变声子箭头的粗度或单根颜色，使用第 12 章的矢量性质栏。

“播放选项”还可控制循环、周期显示方式和键的显示策略。
晶胞内显示会把原子折回周期晶胞；连续显示用于观察跨边界的连续运动。
2D 与 3D 使用同一份模式、相位和外观设置。

17.4 保存和导出

File → 保存项目保留声子条目及显示设置；
File → 导出结构 → .facet 文件导出声子包，保留全部 q 点和模式，
不是把当前画面压成一个静态结构。交换这种声子包不需要另外携带
原始 scf.in / scf.out / matdyn.modes / OUTCAR。

2026-09-28 声子修复包取消单个 q 点模式块的独立 64 MiB 限制，
独立声子包和项目内嵌声子采用同一规则。模式数据仍受整包 2 GiB、
总展开大小 4 GiB 的容量检查约束，并受机器实际内存影响。
用 ftkit 声子修复包生成的大文件，应使用本次 Facet 修复版打开；
较早的 0.1.1 Alpha 即使文件格式兼容，也可能报 ZIP entry exceeds limit。

底部“导出 GIF”用于把当前模式的振动保存为动画，可调整输出尺寸等选项。
GIF 用于演示，不代替保存可切换模式的 .facet。
保存项目后重新打开，可继续选择模式和调整显示。


18  STM：电荷密度与扫描隧道显微镜模拟
==========================================

18.1 输入和入口

打开完整的 CHGCAR、CHG 或 PARCHG 电荷密度，在 Isosurface 中添加 STM。
可视化补齐的数据不能用于 STM。如需偏压能窗对应的物理解释，应在计算阶段
准备相应部分电荷密度；总电荷密度本身不定义能窗。Facet 不代替电子结构计算，
也不会把任意密度阈值自动标成实验中的绝对隧穿电流。

两种模式：
  - 恒高：在指定高度取密度，颜色表示密度大小。
  - 恒流：沿所选法向搜索达到“等值密度”的位置，颜色表示高度。
高度单位 Å；密度单位 e/Å³，其中 e 是电子电荷量的计数单位。
恒流模式中的输入是等值密度，不是安培。

18.2 设定参考面和扫描范围

选择 AB、BC、CA 平面，或输入晶面指数 (hkl)。
恒流模式选择 +n 或 −n，表示从参考面法向的哪一侧真空边界开始搜索。
高度和搜索范围沿参考面法向计量；对倾斜晶胞，不要直接当作晶格 c 长度。

先使用自动估算的初值，再调整“高度”或“等值密度”“搜索 / Å”。
可点击“重新估算”。参数变更后自动更新，计算中可取消；
界面会注明是否暂时显示上一次结果，导出前等待当前结果完成。

出现无交点或真空边界无效的点时，检查扫描侧、阈值、搜索区间和输入数据。
这些点保留为无效区域，不会被当成高度为零的有效点。

18.3 颜色与显示

颜色栏可选择色谱、编辑色标节点和范围。
“着色”可选按密度/按高度或纯色；展开“颜色详细设置”可调整色图和数值范围。
恒流模式的“高度缩放”只放大画面起伏，不改变导出的原始高度数据。
“原结构”和“叠加原子”分别控制整层显示；叠加原子不提供逐个选择。
“叠加设置”控制高度与覆盖范围；新建叠加默认显示键，覆盖为 0–1 × 0–1。
Lattice 独立控制晶胞框。“仅显示面下”隐藏扫描侧上方的原子、键和电荷等值面。

平滑宽度表示高斯核的标准差，单位为 Å。
“密度平滑”先平滑三维输入密度，再计算 STM，会改变计算结果。
宽度单位为 Å，范围为 0–1，0 表示关闭。
“图像平滑”只平滑已计算的显示结果，启用宽度为 0.01–1 Å，0 表示关闭。
新建 STM 时两种平滑都默认关闭；已有文件继续使用保存的设置。
图像平滑可能使峰变低、亮斑变宽，但不补齐原本无效的区域。
空间插值、图像平滑和高度缩放不改写 CSV/JSON 中的原始计算结果。
例如原始峰高为 2 Å，图像平滑后画面上的峰可能更低，原始高度仍为 2 Å。
图片和“仅显示面下”使用显示表面；密度平滑与这些显示设置的作用不同。

极小或较大的数值会用科学计数法显示，例如 0.00005 显示为 5e-5。
点击数值框可查看完整原值；只查看而不修改，不会改变科学数据。

18.4 导出与保存

“导出数据”提供 CSV（含 JSON 元数据）或 JSON，保留结果和计算设置。
应在当前参数计算完成后导出；失败或取消后暂留的旧结果不是新参数的结果。
出图仍使用 File → 导出图片。

STM 设置随项目保存；体数据仍可能引用外部 CHGCAR、CHG 或 PARCHG。
分享项目时一起提供该文件，重开时按提示定位原始资源。


19  本版交互与文件提示
========================

显示范围输入的上限必须大于下限；草稿无效时保留上一次有效显示范围。
GIF 导出面板可拖动。保存预设时可保存修改或另存副本，删除前请阅读保存提示。
外部密度源文件变化或无法读取时，仍保留载入时记录的校验值；
当前视图可继续使用，重开需要匹配的原文件。不同密度应作为新资源导入。
部分较新文件可只读兼容预览，提示中列出未显示内容，并禁用保存、结构导出
以及追加到可编辑项目，以保护原文件。桌面应用禁用并清理表单输入历史。

  图像平滑 — Image smoothing
