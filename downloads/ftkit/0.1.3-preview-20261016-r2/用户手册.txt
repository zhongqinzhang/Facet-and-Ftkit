01  ftkit 是什么，能做什么
==========================

ftkit 把已有的 VASP、Quantum ESPRESSO（简称 QE）计算结果转换成
Facet 文件，用于查看结构、磁矩、轨迹和声子。它负责转换和整理结果，
不运行第一性原理计算，也不代替对计算是否收敛的检查。

ftkit 是独立的终端程序：在计算目录输入 ftkit，再输入任务编号即可使用。
转换在 Linux 上完成，不启动图形界面；将结果复制到装有 Facet 的电脑查看。
使用本发行包无需安装 Python、Rust 或 Facet；查看结果时才需要 Facet。

任务速查：

  101  OUTCAR 弛豫 / AIMD
       输入：OUTCAR
       输出：trajectory.facet（结构序列，带逐帧属性）

  103  NEB 反应路径
       输入：当前目录中的编号图像子目录，各含 CONTCAR、OUTCAR
       输出：neb-path.facet（结构序列，含各图像能量）

  201  单个磁结构
       输入：OUTCAR
       输出：magnetic.facet（静态结构和磁矩矢量）

  202  批量磁结构
       输入：当前目录的一级子目录，各自读取 OUTCAR
       输出：magnetic-batch.facetproj（多个独立静态结构组成的项目）

  301  VASP 声子模式
       输入：包含完整声子结果的 OUTCAR
       输出：phonons.facet（声子数据）

  302  QE 声子模式
       输入：scf.in、scf.out、matdyn.modes，或包含它们的 ZIP
       输出：phonons.facet（保留输入中的全部 q 点和模式）

.facet 文件可以保存静态结构、结构序列或声子数据，Facet 会按文件内容打开。
.facetproj 是项目文件，可管理多个结构及其显示设置。
文件名中的 batch 表示“批量”。

默认输出写到运行 ftkit 时的当前目录，不一定是输入文件所在目录。
输出文件已存在时直接替换，不询问；想保留旧结果，先改名或用 -o 指定新名字。
301 和 302 的默认输出同名，在同一目录使用时可分别指定不同文件名。
不要把 -o 指向 OUTCAR、CONTCAR 或其他输入文件。


02  安装、验证与升级
====================

2.1 下载、校验与安装

在本版本下载页获取以下两个文件，并放在同一目录：
  ftkit-0.1.3-preview-20261016-r2-linux-x86_64.tar.gz
  SHA256SUMS.txt

可使用页面中的“下载发行包”链接；也可打开仓库中的文件后选择
Download raw file。SHA256SUMS.txt 也应下载原始文件，不要保存整个网页。
GitHub Release 自动列出的 Source code 归档不是要安装的软件包。

在终端进入这两个文件所在目录，先校验下载是否完整：
  sha256sum -c SHA256SUMS.txt

确认显示 OK 后再解压；若校验失败，重新下载并核对文件，暂不继续安装。
请在准备长期保留软件的位置解压，例如自己的 software 目录。
以下命令假定压缩包已放在当前目录：

  tar -xzf ftkit-0.1.3-preview-20261016-r2-linux-x86_64.tar.gz
  cd ftkit-0.1.3-preview-20261016-r2-linux-x86_64
  bash verify.sh

verify.sh 会检查文件校验和、程序启动和代表性转换，全部通过后调用
install.sh，将这个解压目录加入 Bash 的 PATH。PATH 是终端寻找命令的目录列表。
无需管理员权限，程序不会被复制到 /usr/bin。

当前终端还需要执行一次：

  source "$HOME/.config/ftkit/env.sh"
  ftkit --version
  ftkit --help

原因是 bash verify.sh 运行在子进程中，不能改变已经打开的父终端环境。
安装脚本已写入 Bash 启动配置，新开的 Bash 终端会自动找到 ftkit。

验证报告在解压目录下 verification-随机字符/report.txt。
成功提示只代表脚本覆盖的自动检查；交互终端和 Facet 中的显示仍需人工查看。
示例数据在 example/，可以拿它们练习，不必先准备自己的计算结果。

2.2 用随包示例完成第一次转换

安装并执行上述 source 命令后，从软件解压目录进入磁结构示例目录：
  cd example/magnetic
  ftkit -task 201 -o first-magnetic.facet

成功后，当前目录会生成 first-magnetic.facet。把它复制到装有 Facet
的电脑并打开，即可查看结构与磁矩箭头；结果查看方法见第 10 章。
练习结束后，回到软件解压目录：
  cd ../..

其他随包示例：
  example/OUTCAR       VASP 声子输入，用任务 301
  example/qe/          QE 三文件输入，用任务 302
  example/soc/OUTCAR   非共线 / SOC 磁结构输入，用任务 201

2.3 其他使用方式

以下命令均从软件解压目录执行。

只验证，不修改 PATH：
  bash verify.sh --no-install

只配置 PATH，不跑完整转换验证：
  bash install.sh

不配置 PATH，直接运行：
  ./ftkit

也可以用程序的绝对路径，例如：
  "$HOME/software/ftkit-0.1.3-preview-20261016-r2-linux-x86_64/ftkit" --version

安装脚本目前针对 Bash，依赖常见的 coreutils、awk、grep、cmp；
unzip 是部分可选检查使用的工具。没有 Conda/pip/apt 安装入口。
本下载目录提供可直接使用的程序包，不需要克隆仓库或从源码编译。

2.4 安装位置、升级与卸载

从旧版升级：
  新版只提供 ftkit 命令。安装器迁移旧版管理的 PATH 区块，
  保留你的其他 Bash 配置。旧程序目录和旧环境文件不会被删除。
  不创建旧命令兼容入口；已有批处理脚本需改用 ftkit。
  若标记区块残缺或首尾名称不一致，安装失败且不发布新配置。

安装原地使用解压目录中的 ftkit：
  - 写入 $HOME/.config/ftkit/env.sh。
  - 在 $HOME/.bashrc 中维护带标记的 ftkit PATH 区块。
  - 在 Bash 优先读取的登录配置中维护同样区块：
    已存在的 .bash_profile、.bash_login、.profile 中按上述顺序取第一个；
    均不存在时创建 .bash_profile。
重复安装会更新自身区块，不应重复追加许多相同的 PATH 条目。
目录可含空格；安装目录不能含冒号或换行。

不要安装后删除或搬走解压目录。需要移动时，在新位置重新运行 install.sh。
升级时解压到新目录，验证并安装，然后再次 source 环境文件：
  hash -r
  command -v ftkit
  ftkit --version
确认指向新版本后再自行整理旧目录。

取消安装时，在上述 Bash 配置中删除以下两个标记之间的 ftkit 区块：
  # >>> ftkit PATH >>>
  # <<< ftkit PATH <<<
再移除 ftkit 的 env.sh 和不再需要的软件目录，重新打开终端。
不要删除 Bash 配置文件中的其他设置。

2.5 系统要求与预览版验证范围

程序面向 Linux x86_64，不能直接作为 Windows 或 macOS 程序运行。
安装与验证脚本要求 Bash 4+，以及 coreutils、awk、grep、cmp 等常见工具；
unzip 用于部分可选检查。程序采用静态 musl 构建，不动态依赖 glibc。

本预览版尚未完成 Linux 实机验证，静态链接也不保证旧内核兼容，
尤其是内核 2.6.32 等旧环境。请先在自己的机器运行 verify.sh；
若失败，保留终端输出和验证报告，按第 12 章反馈。
包内 BUILDINFO.json 记录构建信息与已有验证范围。

查看系统信息：
  uname -m
  uname -r
  cat /etc/os-release

uname -m 应显示 x86_64。较旧的 Red Hat / CentOS 系统若没有
/etc/os-release，可查看：
  cat /etc/redhat-release


03  五种运行方式
================

以下以当前目录的 VASP 声子 OUTCAR 为例。使用其他任务时，更换任务号，
并按对应章节准备输入。菜单、管道和答案文件方式均使用该任务的默认输入；
需要指定输入路径或输出文件名时，使用方式二。

方式一：交互菜单
  ftkit

看到菜单后输入 301 并回车；输入 0 退出。
程序执行一项任务后结束，不会再询问输入文件名、输出名或第二个任务。

方式二：命令加参数
  ftkit -task 301 -i OUTCAR -o vasp-phonons.facet

适合脚本和批处理，也用于选择非默认输入输出位置。
参数之间用空格分隔；带空格的路径加引号，例如：
  ftkit -task 201 -i "FM state/OUTCAR" -o "FM state.facet"

方式三：echo 管道
  echo 301 | ftkit

也可使用更便于精确控制换行的 printf：
  printf '301\n' | ftkit

方式四：组合命令管道
  (echo 301; echo) | ftkit

这与方式三运行同一任务；多出的空行被忽略。

方式五：答案文件重定向
  printf '301\n' > cmd.in
  ftkit < cmd.in

cmd.in 文件名可自定，内容只需一行：
  301

目前答案流只接收一个任务号和可选空行，总长不超过 4096 字节。
不能仿照其他程序在后面继续填写路径、阈值或第二个任务号；
遇到多余非空内容会报错。自选文件请用方式二。
运行 ftkit -task 0 不等于菜单退出；0 只用于菜单/答案流。


04  101：OUTCAR 弛豫与 AIMD 轨迹
================================

AIMD 指从头算分子动力学。此任务读取 OUTCAR 中的弛豫步骤或 AIMD 帧。
在相应计算目录中执行：
  ftkit -task 101

指定文件：
  ftkit -task 101 -i run/OUTCAR -o run-trajectory.facet

默认生成 trajectory.facet；使用 -o 时，打开指定的输出文件。
在 Facet 中可逐帧查看结构、原子力箭头和能量变化。
读取的内容包括晶胞、原子位置、力、TOTEN 和最大原子力；
AIMD 中还能保留文件中可用的时间/温度等信息。
TOTEN 是 VASP 输出的自由能量字段，单位 eV；力单位 eV/Å。

本版默认把本次轨迹中最低的可用 TOTEN 作为零点，
每帧输出能量 = 该帧 TOTEN − 本次轨迹最低 TOTEN。
例如 −10、−12、−11 eV，输出为 2、0、1 eV；能量差保持一致。
Facet 中显示为 Relative energy (eV)，即相对能量；本次输出最低值仍为零。
缺失能量的帧仍标为缺失；只有一个有效能量时为零；全部缺失时无能量通道。
力、温度、时间和结构不受影响，无需增加命令参数。
旧版生成的 .facet 不会自动改用此零点；需要时请用本版重新转换，
并用新的输出文件名保留旧结果。

弛豫步只表示优化迭代顺序，不解释成真实时间。
AIMD 的时间依赖 OUTCAR 中的 POTIM；缺失输入属性不会凭空补成物理数据。
当前主要对应 IBRION = 0 的分子动力学和 IBRION = 1、2、3 的弛豫输出。

当前限制：
  - 不支持 XDATCAR，没有任务 102。
  - --stride 虽被参数解析接受，但尚未执行抽帧，不要依赖它减少帧数。
  - 当前轨迹保留在内存中，大 OUTCAR 的内存需求会随帧数增加。
  - 转换失败或被中断后，结果文件可能不完整。请检查输出并重新转换，
    不要仅凭文件存在就认为转换成功；建议始终用新输出名保留已有结果。


05  103：NEB 反应路径
====================

本任务读取已完成计算的 NEB 反应路径。这里的“图像”指路径上的一个结构，
不是图片；每个图像保存在一个编号子目录中。

目录示例：
  neb/
    00/CONTCAR
    00/OUTCAR
    01/CONTCAR
    01/OUTCAR
    02/CONTCAR
    02/OUTCAR

进入 neb 后：
  ftkit -task 103

从其他位置执行：
  ftkit -task 103 --root neb -o neb-path.facet

也可用 -i neb 指定根目录，但不要同时写 -i 和 --root。
程序读取名字可解析为编号的一级子目录，按编号排序。
每个参与的图像目录都需要 CONTCAR 和 OUTCAR；请自行准备端点文件。
不会自动用 POSCAR 代替缺失的 CONTCAR。

在 Facet 中各图像作为路径上的一帧。每个图像先取 OUTCAR 的最终 TOTEN，
再减去整条路径（含端点）的最低最终 TOTEN，
写出相对能量，最低值为零，单位仍为 eV；不是各目录分别归零。
例如 00、01、02 的最终能量为 −10、−12、−11 eV，输出为 2、0、1 eV。
101 / 103 的每份输出各自选取零点，不宜拿不同输出的相对值比较绝对能量。
这些帧不是分子动力学时间步；本任务也不自动判断过渡态或报告反应势垒。
输入不完整会报错，不采用磁结构任务 202 的跳过坏目录策略。
103 不支持 --stride。与 101 一样，失败或中断后需检查输出完整性，
建议用新的输出文件名保留已有结果。


06  201：单个磁结构
====================

在磁计算目录中执行：
  ftkit -task 201

指定输出名，或改变共线磁矩的显示轴：
  ftkit -task 201 -i OUTCAR -o FM.facet
  ftkit -task 201 --axis x

输出为静态结构，不显示轨迹播放栏。
读取 OUTCAR 中最后一份能够完整配对的结构和逐原子磁矩，
不是简单取 POSCAR、初始 MAGMOM 或任意一张磁矩表拼在一起。

共线计算：
  每个原子有一个带符号的磁矩，默认沿 +z / −z 显示。
  --axis x、--axis y、--axis z 可指定显示轴；默认 z。
  这是显示约定，不表示共线计算额外求出了三维自旋方向。

非共线或 SOC 计算：
  读取三分量磁矩并处理 SAXIS，输出笛卡尔坐标中的方向。
  --axis 只用于共线显示，不应用来旋转非共线结果。

单位为 μB（玻尔磁子）。使用逐原子 magnetization 的 tot 列；
不是初始 MAGMOM，也不额外合成轨道磁矩。
OUTCAR 未打印可用磁矩时会报错，不会把缺失磁矩填成零。
计算需按 VASP 的要求输出逐原子磁矩表，例如正确设置投影输出。

尾部不完整时可能使用此前完整配对的记录，并报告原因；
得到可转换文件不表示计算已经收敛，请仍检查自己的 VASP 计算状态。


07  202：批量磁结构项目
========================

目录示例：
  magnetic-comparison/
    1-AAABBB/OUTCAR
    2-AB/OUTCAR
    3-FM/OUTCAR

在 magnetic-comparison 中执行：
  ftkit -task 202

得到 magnetic-batch.facetproj。打开后项目树包含：
  1-AAABBB
  2-AB
  3-FM

每个对象是独立静态结构，名字就是子目录名；点击名字切换查看。
也可指定根目录和共线显示轴：
  ftkit -task 202 --root magnetic-comparison --axis z -o comparison.facetproj

只扫描一级子目录，不递归到更深层；根目录自身的 OUTCAR 不作为一个子结构。
各目录沿用 201 的最后完整结构/磁矩配对规则。
缺失 OUTCAR、缺少磁矩或无法解析的目录会跳过，结束时汇总原因。
  - 全部有效：退出状态 0。
  - 部分成功：仍写出项目，退出状态 3；请阅读跳过目录列表。
  - 没有任何可用结构：退出状态 2，不用空项目替换已有结果。

整个批量项目共用初始箭头比例和粗度，便于跨结构比较。
例如一份结构最大磁矩为 2 μB，另一份为 4 μB，共同初始比例下后者最长箭头
是前者两倍长。分别运行两次 201 会各自定标，不能仅比较屏幕箭头长度。


08  301：VASP 单 q 点声子
==========================

在包含声子计算 OUTCAR 的目录中：
  ftkit -task 301

指定文件：
  ftkit -task 301 -i OUTCAR-phonon -o vasp-phonons.facet

需要完整的晶胞、原子、质量、频率和本征矢量信息。
输出一个声子类型的 .facet，其中有全部模式，而不是每个模式单独一个文件。
若有 N 个原子，完整数据应有 3N 个模式，例如 80 个原子对应 240 个模式。

q 表示声子波矢，Γ 点对应 q = 0。
此任务只读取 VASP 计算晶胞的 Γ 点声子。
如果用了超胞，它仍是该计算晶胞的 Γ 点；不自动展开成原胞的声子色散。
转换时处理 VASP 模式的质量约定，输出统一的位移数据；
用户不需要再手动除原子质量。

在 Facet 中切换模式、频率单位，显示位移箭头或播放振动。
频率的虚频标记会保留；cm⁻¹、THz、meV 是同一频率的不同显示单位。
301 不支持 --axis、--root、--stride，也不生成预先烘焙好的动画帧。

本版的单 q 点声子模式数据块没有独立的 64 MiB 上限。
仍保留 10000 原子、结果归档 2 GiB 和总展开大小 4 GiB 等限制；
实际内存不足仍可能导致进程终止。请用第 10 章列出的配套 Facet 打开结果。


09  302：QE 声子
================

9.1 目录输入

将以下文件放在同一目录：
  scf.in
  scf.out
  matdyn.modes

在该目录执行：
  ftkit -task 302

或从其他目录：
  ftkit -task 302 -i qe-result -o qe-phonons.facet

目录方式使用上述文件名。不要只提供 scf.out 就期待它含有完整声子模式。

9.2 显式指定三个文件

文件名或目录不同的时候：
  ftkit -task 302 --scf-in calc/scf.in --scf-out calc/scf.out --modes modes/custom.modes -o qe-phonons.facet

--scf-in、--scf-out、--modes 必须一起给出，不能与 -i 混用。

9.3 ZIP 输入

  ftkit -task 302 -i qe-result.zip -o qe-phonons.facet

ZIP 可以包含子目录，但 scf.in、scf.out、matdyn.modes 各只能匹配到唯一一份。
把多个计算塞在同一个 ZIP 中造成同名文件歧义时会报错。
程序直接读取归档，不把归档成员解压到当前计算目录。

9.4 数据含义与范围

matdyn.modes 必须是 matdyn.x 的 flvec 输出，包含复数本征位移。
频率列表、fleig 输出、任意 dynamical-matrix 文件或电子声子耦合输出
不能当作本任务的 matdyn.modes 使用。

保留输入中的所有 q 点及其模式、复数位移、频率；不只保留 Γ 点。
q 点按输入顺序保留，不补算缺失点。多 q 点文件在 Facet 中显示声子色散。
QE 位移采用输入对应的质量约定，不再重复做 VASP 的质量修正。

输入大小限制：
  scf.in 8 MiB，scf.out 64 MiB，matdyn.modes 256 MiB；
  ZIP 最多 10000 个成员，并对目标文件的实际解压大小限流。
这些是拒绝过大输入的限制，不是峰值内存保证。


10  在 Facet 中查看和调整结果
==============================

本仓库提供的配套查看器为 Facet 0.1.1-alpha-20261016-i18n（Windows x64）：
  https://github.com/zhongqinzhang/Facet-and-Ftkit/tree/main/downloads/facet/0.1.1-alpha-20261016-i18n

将生成的 .facet 或 .facetproj 复制到装有 Facet 的电脑，在 Facet 中打开。
同为 0.1.1 Alpha 的早期安装包可能不支持本版生成的格式，请核对完整发行版本。
双击文件若仍交给旧 Facet，先保存并关闭旧进程，再用上述版本打开。
出现 project schema version 20 requires a newer application，表示
当前查看器不能读取该项目格式，不是计算数据已经损坏；不要手改版本号。

10.1 轨迹、磁结构和声子的区别

101/103 是序列：有逐帧播放与相应的物理量。
201 是静态磁结构：直接显示磁矩，没有轨迹播放栏。
202 是多个静态磁结构的项目：左侧按目录名切换。
301/302 是声子：使用专门的 q 点、模式、频率、振幅和相位控件。

10.2 箭头长度、粗度和颜色

在矢量列表或画面中选择目标，右侧性质栏可以调整显示长度和粗度。
100% 表示该对象保存的尺寸基准；改变显示百分比不改变科学数值。
列表行左侧颜色圆点可以直接点击：
  - 已选中矢量时，只改当前选择。
  - 未选中时，修改该行代表的单根或整组。
不必先展开外观设置。一次连续改色可撤销；Esc 取消本次改色。

首次打开新生成的结果时，Facet 会采用相应的默认显示比例，
通常从面板的 100% 开始调整即可。
202 整个项目共用一套初始比例，201 每次转换独立定标；
因此，不同 201 文件的箭头长度不能直接用于比较磁矩大小。

磁矩默认“中段”位置让箭头穿过原子，球体会遮住内部的一截。
要让箭头从球外露出，可在外观设置中选择表面位置。
科学磁矩没有因遮挡而减少。

10.3 声子动画和单位

只有一个 q 点时显示一条频率线及所有模式点；
频率重合的模式可用模式下拉框分别选择。
多个 q 点时保留色散图。单位在 cm⁻¹、THz、meV 间切换。

位移箭头表示原子离开平衡位置的方向和大小：
平衡位置箭头为零，最大位移时最长，运动到另一侧时反向。
它不是速度箭头；一维例子是左右振动的原子在中心处没有位移箭头。
播放时使用固定显示比例，不会每帧把当前最大箭头重新拉长。

“振幅”调节原子的演示位移，也会改变位移箭头；
矢量“显示长度”只调箭头，原子振幅不变。
“导出 GIF”生成演示动画；保存 .facet 保留可切换的全部模式。

10.4 保存修改

保存 .facet / .facetproj 可以保留长度、粗度、颜色等外观设置。
已保存的外观优先于新文件的默认值，重开后继续使用保存的设置。
用 ftkit 重新转换同一个输出名，会替换此前在 Facet 中保存的外观修改；
要保留排版好的结果，请另存为其他文件名。


11  命令参数与退出状态速查
==========================

基本命令：
  ftkit                 菜单模式
  ftkit -h              帮助；也可用 -help、--help
  ftkit -v              版本；也可用 --version
  ftkit -task 编号      执行任务；也可用 --task

通用文件参数：
  -i 路径               输入；也可用 --input
  -o 路径               输出；也可用 --output
  --overwrite           兼容旧命令，现已默认覆盖，无需填写

专项参数：
  --root 目录           103、202 的根目录，不能与 -i 同时用
  --axis x|y|z          201、202 共线磁矩的显示轴
  --scf-in 文件         302，与下面两项一起使用
  --scf-out 文件        302
  --modes 文件          302
  --stride 正整数       101 接受但尚未生效，当前不要依赖它

不支持的选项、重复选项、缺少参数值会报错。
路径以 - 开头时可加 ./，例如 -i ./-special/OUTCAR。
不要写成 ftkit 301 或 ftkit -task=301；任务号作为单独参数传入。

退出状态：
  0    成功，或菜单输入 0 退出
  2    输入、参数、解析或输出错误
  3    202 部分成功，项目已写出，部分目录被跳过
  130  201/202/301/302 在提交前响应 Ctrl+C 中断

Bash 中紧接任务后查看：
  echo $?

在脚本中处理批量任务时，不要把 3 当作“完全没有输出”。
201/202/301/302 在结果准备完整后才替换目标文件；在此之前失败会保留旧输出。
结果已经成功写出后到来的中断，不会把成功状态改为失败。
101/103 的失败和中断处理有不同限制，见第 4、5 章。


12  常见问题、已知限制与反馈
==============================

输入 ftkit 提示 command not found：
  先 source "$HOME/.config/ftkit/env.sh"；核对 command -v ftkit。
  如果搬动过软件目录，在新位置重新运行 bash install.sh。

Permission denied：
  确认 tar 解压保留执行权限；可在软件目录执行 chmod +x ftkit。
  若目录所在文件系统禁止执行，需要换到允许执行的位置。

cannot execute binary file / 启动失败：
  核对 uname -m 应为 x86_64，以及软件包校验和。
  旧内核兼容不能通过是否静态链接来判断；提供系统信息和验证报告。

no OUTCAR / cannot open：
  先执行 pwd、ls，确认当前目录与大小写。
  在计算父目录中运行 201 不会自动选择子目录；使用 -i 或任务 202。

缺少 magnetization / 磁矩记录不完整：
  核对 OUTCAR 是否输出逐原子磁矩，计算是否完成。
  ftkit 不会用初始 MAGMOM 或全零箭头替代缺失结果。

301 模式数量不足或缺少质量：
  使用完整声子 OUTCAR，不是只截取频率段。
  输入必须包含可匹配的结构、质量和完整本征矢量。

ZIP entry exceeds limit：
  这是结果文件内部数据块超限，与 OUTCAR 文件大小或机器剩余内存不同。
  本版与配套 Facet 已取消同一 q 点声子模式块的独立 64 MiB 上限，
  但其他类型的数据块仍有容量限制。若声子结果仍报 limit 67108864，
  先核对两款程序的完整发行版本；旧查看器可能拒绝打开新生成的大文件。
  更新后仍失败时，请保留完整错误信息并反馈。

其他容量限制：
  101/103/301/302：结果归档最多 2 GiB，总展开大小 4 GiB。
  101/103 的轨迹帧及其他非模式数据块仍限制 64 MiB；声子模式块不再单独限额。
  201/202：结果归档最多 64 MiB，总展开大小 128 MiB；202 按整份项目计算。
  声子数据最多 10000 原子、100000 个 q 点；302 输入限制见第 9 章。
  以上均为程序固定阈值，不是机器剩余内存检测。

302 缺少文件或 ZIP 匹配不唯一：
  对照第 9 章检查三个文件。多个计算请分别转换。

只有一个 q 点，为什么不是一条完整色散曲线：
  单点只有该 q 点的模式频率。程序不凭空插值出其他 q 点。
  VASP 超胞 Γ 点也不会自动展开为原胞色散。

升级后旧 magnetic.facet 仍被当成一帧轨迹：
  早期输出曾用序列表示磁结构。用 0.1.3 重新运行 201；
  新文件明确为静态结构，旧文件不会按名称自动重写类型。

本预览版的主要限制：
  - 不支持 XDATCAR 转换。
  - 101 的 --stride 尚未生效，超大轨迹可能占用较多内存。
  - 101/103 失败或中断后需检查输出，建议使用新输出名保护旧结果。
  - AIMD/NEB 输出变体的验证范围有限；遇到解析失败时请提供可复现样例。
  - Linux 实机验证尚未完成，旧内核兼容性未确认，见第 2.5 节。

问题反馈：
  https://github.com/zhongqinzhang/Facet-and-Ftkit/issues

请说明使用的是 Ftkit，并提供：
  - 完整发行版号 0.1.3-preview-20261016-r2，以及 ftkit --version 的输出。
  - 执行的完整命令、输入文件的目录关系和复现步骤。
  - uname -m、uname -r、系统版本及终端错误原文。
  - 如运行过 verify.sh，附上 verification-*/report.txt。
  - 可以公开分享的最小输入样例。
