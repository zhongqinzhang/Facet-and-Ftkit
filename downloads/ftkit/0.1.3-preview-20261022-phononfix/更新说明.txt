1. 0.1.3（2026-10-22 声子兼容修复）
====================================

修复 301 将 VASP 质量修正段的双行标题误判为重复段的问题，
同时支持只输出质量修正段的相同标题形式。
晶胞和有效 POMASS 校验延续到文件末尾；矛盾输入报错，旧输出保留。
真正的重复段、模式截断和原始/修正模式不一致仍会被拒绝。
命令参数、模式顺序、质量修正规则和文件格式保持不变。

真实 VASP 6.5.1 / IBRION=5 OUTCAR：28 个原子、1 个 Γ 点、
84 个模式，其中 3 个虚频；已完成转换、原生回读和逐模式数据核对。
本机通过 49 项 Ftkit 测试及另行启用的 1 项真实文件回读测试。
Linux 静态程序已交叉构建，ELF 审计结果见 BUILDINFO.json。
三台目标机实测仍待完成。仓库级 pnpm check / pnpm build 最终均通过。

本次包为 ftkit-0.1.3-preview-20261022-phononfix-linux-x86_64.tar.gz。
沿用 20261016-r2 的共享数据层来源及声子 schema 5。
安装后请使用 ftkit，不要继续运行旧 fakit。


2. 0.1.3（2026-10-16 相对能量）
================================

101 的弛豫 / AIMD 轨迹、103 的 NEB 路径默认输出相对能量：
所有能量减去本次输出中的最低能量，最低值为零，单位 eV。
103 在所有参与图像及端点的最终 TOTEN 中取最低值。
例如 −10、−12、−11 eV 转换为 2、0、1 eV。

r2 包的物理量名称统一为 Relative energy (eV)。
同日首包名称中的 TOTEN、min=0 已删去，能量归零规则不变；
菜单、结果摘要排版和 .facet 文件格式不变。
101 缺失的能量保持缺失，力、温度、时间和结构不变；其他任务不变。
菜单、命令参数、管道和重定向调用均默认生效，无需新参数。
现有结果文件不自动修改；重新转换才采用新零点。
当时包为 ftkit-0.1.3-preview-20261016-r2-linux-x86_64.tar.gz。
同日无 r2 后缀的首包已包含归零行为，但仍使用较长名称；
之前日期的 0.1.3 预览包不包含归零行为。
本机已通过 45 项 Rust 测试；真实弛豫样例的最低能量为零。
Linux 实机验证仍待完成，完整构建与验证信息见包内 BUILDINFO.json。


3. 0.1.3（2026-10-11 Ftkit 改名）
====================================

软件名称统一为 Ftkit，命令、可执行文件和安装包统一为 ftkit。
源码包、帮助提示、示例、手册和当前论文图稿同步更新。
新版只提供 ftkit 命令，批处理脚本中的旧命令需要改用新名称。
安装配置改为 ~/.config/ftkit/env.sh，旧版管理的 PATH 区块会迁移；
其他 Bash 配置保留，重复安装不会重复添加。
任务号、参数、默认输出、科学数值和已有结果文件的使用方式保持。
版本号仍为 0.1.3，完整构建与验证信息见本次包的 BUILDINFO.json。



4. 0.1.3（2026-09-28 修复包）
============================

使用包名含 phononfix 的配套 ftkit 与 Facet 修复包。

删除 301 在读取原子数时执行的 256 MiB 工作集估算限制。
原先 555 原子会在尚未读取模式时直接报错，现在继续解析完整模式。
保留计数溢出、原子数与科学数据完整性校验；不修改文件格式或模式数值。
同时取消共享文件读写层对声子模式块的独立 64 MiB 上限，
统一覆盖独立声子文件、项目内嵌声子和延迟模式读取。
555 原子 / 1665 个密集模式已通过转换与原生回读；
超过 128 MiB 的模式块也通过项目保存和重开。

轨迹等其他类型的数据块上限保留，整包 2 GiB、总展开大小 4 GiB 等
检查继续生效。其他任务的容量限制见手册第 12 章。
旧版 Facet 可能仍拒绝大文件，需要同步使用本次 Facet 修复包。
确切测试结果见 BUILDINFO.json；Linux 实机验证尚未完成。


5. 0.1.3（2026-09-25）
======================

磁矩与声子尺寸
--------------
磁矩初始尺寸复用手动新建矢量的尺寸规则，长度采用公共基准的 85%。
202 整批结构共用比例，保留各原始磁矩大小、方向、红色和中段位置。
Facet 0.1.1 Alpha 的新声子默认长度采用公共基准的 50%，保持原粗度、
橙色与表面位置。声子默认由 Facet 初始化，磁矩默认由 ftkit 写入。
已保存外观优先，不进行反复缩短。

终端与文档
----------
保留边框横幅和分组菜单；菜单不列输出文件名，摘要只列结果文件名。
删除 No Facet installation is needed... 宣传句、Elapsed 和 Next 行。
所有任务默认覆盖同名输出，不询问；--overwrite 保留作为兼容参数。
新增中文使用手册，覆盖六个任务、五种调用方式、安装与常见问题。
本版配套 Facet 0.1.1 Alpha；请升级旧查看器后再打开新版项目。

安装
----
bash verify.sh 在验证通过后配置 Bash PATH；当前终端执行一次
source "$HOME/.config/ftkit/env.sh"，新 Bash 自动生效。
--no-install 可只验证；install.sh 可单独配置 PATH。

7. 验证范围与限制
==================

本机构建验证覆盖 Rust 转换接口、真实 Facet 浏览器查看与文件往返、
终端输出、安装脚本和 ELF/归档审计；具体执行记录随 BUILDINFO.json 提供。
Linux 包为静态 musl x86_64 构建，不要求 Python。
静态 ELF 审计不等于在旧内核运行成功，三台目标机仍需分别实际运行 verify.sh。
因此本版仍作为 preview 包交付。

101 的 --stride 尚未生效，且 101/103 尚未采用统一取消/原子发布流程；
完整限制和使用建议见中文手册。未把这些待办标为已完成。
